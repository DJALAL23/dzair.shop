# Introduction

Wocart is a cash-on-delivery commerce platform built for Algeria. Merchants get a dashboard, a themeable storefront, and a typed REST API for orders, delivery, catalog, customers, reviews and store settings.

This site is the developer reference for that platform. Its API reference and SDK typings are generated from the API's own OpenAPI document and the published packages, so endpoints and types match the code that ships. To build a theme, start from the theme starter (`npm create wocart-theme`), described in the [Theme SDK](/sdk/theme/starter) guide.

## How this site is organized

- **Guides** cover the concepts that are shared by every endpoint: authentication, errors, webhooks and the MCP server.
- **API reference** is generated from the live OpenAPI document. Operations include their parameters or request body, response schema and — where the route declares one — a security requirement. Every operation has a playground.
- **SDK references** are generated from the published TypeScript declarations. The Storefront SDK and Theme SDK guides explain them, with complete quick starts.
- **Every page is also Markdown** at its URL plus `.md`, and [`/llms.txt`](/llms.txt) indexes them all.

## What you can build

- **A storefront theme** with the storefront engine and the theme contract, shipped as a normal npm package.
- **Order and delivery automations** that create orders, hand them to a carrier, and react to shipment events.
- **Catalog and customer tools** for a back office, an importer or a support workflow.
- **AI agent integrations** through the OAuth-secured MCP server, with tools scoped to the signed-in user's permissions.

## Local preview

The API reference is generated from the OpenAPI document served by cod-server. When running locally, start the server with `npm run dev` in `cod-server`, then run `npm run generate` in `cod-docs` after changing routes. The server selector in the API reference points at `http://localhost:8787` by default.
