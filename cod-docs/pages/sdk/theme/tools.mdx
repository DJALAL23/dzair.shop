# Tools

You do not need a special tool to build a Wocart theme: Astro, the two
packages and these pages are enough.

## What to use

| Need | Use |
| --- | --- |
| A working example to copy | The Theme-00 [reference implementation](/sdk/theme/reference-implementation) |
| The full setup sequence | [Build a complete theme](/sdk/theme/tutorial) |
| Safe changes to copy, images and layout | [Customize a theme](/sdk/theme/customize) |
| A working theme to start from | The [quick start](/sdk/theme/build): every file, every command |
| Rules for an AI agent | The [AI agent kit](/sdk/theme/agents) |
| A repeatable release check | [Testing a theme](/sdk/theme/testing) |
| A pre-flight list | [Production and upgrades](/sdk/theme/production) |

If you only need a custom design for one store and nobody will edit it from a
dashboard, you need none of the theme layer. Build an Astro storefront with
[`@wocart/storefront`](/sdk/storefront).

## Which path should you take?

| Your goal | Start with |
| --- | --- |
| A fixed custom storefront for one shop | Astro + [`@wocart/storefront`](/sdk/storefront) |
| A theme a merchant can edit | The [quick start](/sdk/theme/build), then [Build a complete theme](/sdk/theme/tutorial) |
| A theme to share or sell | Build it, then [Manifest](/sdk/theme/manifest), [Testing](/sdk/theme/testing) and [Production and upgrades](/sdk/theme/production) |
| Build with an AI agent | The [AI agent kit](/sdk/theme/agents) |
