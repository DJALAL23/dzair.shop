# الصفحات والقوائم

صفحات المتجر والقوائم وصفحات الهبوط محتوى التاجر. يقرأها SDK؛ ويقرر القالب
مكانها وكيف تبدو.

## صفحات المتجر

تعيد `pages.get(slug)` صفحة قانونية أو مخصصة منشورة:

```ts
const page = await store.pages.get("terms");

if (!page) return Astro.rewrite("/404");

page;
// {
//   id,
//   kind: "terms" | "privacy" | "refund" | "shipping" | "custom",
//   slug,
//   locale,
//   title,
//   bodyHtml,
//   metaTitle,
//   metaDescription,
// }
```

`bodyHtml` منظَّف مسبقًا من الخادم. اعرضه بـ`set:html` ولا تعِد تنظيفه إلى شكل
مختلف:

```astro
<article>
  <h1>{page.title}</h1>
  <div set:html={page.bodyHtml} />
</article>
```

slug مسوّدة أو غير منشور أو مجهول يعيد `null`. هذا 404 حقيقي، لا صفحة بلا متن.

حلّ الصفحات القانونية بـ`kind` عندما تسمّي قاعدة إحداها. فقد يعيد التاجر تسمية
slug، لكن صفحة الشروط تبقى `kind: "terms"`.

```ts
const terms = config.pages.find((item) => item.kind === "terms");
```

تُجلب `pages.get` من جديد في كل استدعاء. ويصل تعديل التاجر إلى عرض الخادم
التالي، مرهونًا بذاكرة مسارك المؤقتة.

## القوائم

تعيد `menus.get(handle)` شجرة قائمة:

```ts
const menu = await store.menus.get("main-menu");

menu;
// {
//   handle: "main-menu",
//   title: "Main menu",
//   items: [
//     {
//       label: "Women",
//       href: "/category/women",
//       type: "category",
//       children: [],
//     },
//   ],
// }
```

لكل عنصر:

| الحقل | المعنى |
| --- | --- |
| `label` | بلغة العميل عندما تكون مترجمة |
| `href` | مسار متجر بلا بادئة لغة، أو عنوان URL المطلق للتاجر |
| `type` | `home` أو `catalog` أو `category` أو `product` أو `page` أو `landing` أو `url` |
| `children` | عناصر متداخلة، بثلاثة مستويات كحد أقصى |

العناصر التي لا تؤدي إلى مكان عام محذوفة مسبقًا. لا تعِد فحص الظهور.

وطّن مسارات المتجر فقط (عبر `localizeHref`)؛ واترك عناوين URL الخارجية كما هي:

```astro
---
import { localizeHref } from "@wocart/storefront";
---
<a href={localizeHref(item.href, config.locale, routing)}>{item.label}</a>
```

قائمة مجهولة أو قراءة فاشلة تعيد `null`. اعرض تنقّلك الاحتياطي الخاص، لا ترويسة
فارغة.

القائمة شجرة، لذا اعرضها بشكل عودي وحافظ على RTL/LTR بـ`dir` الصفحة. ولا يعرضها
SDK لك.

## صفحات الهبوط

تعيد `pages.landing(slug)` صفحة هبوط منشورة مع مجموعة صور مرتّبة، واختياريًا منتج
واحد مرتبط:

```ts
const landing = await store.pages.landing("ramadan");

if (!landing) return Astro.redirect("/", 302);
```

والشكل:

```ts
type LandingPage = {
  id: string;
  slug: string;
  name: string;
  status: "draft" | "published" | "archived";
  imageGap: number;
  metaTitle: string | null;
  metaDescription: string | null;
  publishedAt: string | null;
  images: Array<{
    id: string;
    src: string;
    altText: string | null;
    position: number;
    width: number | null;
    height: number | null;
  }>;
  product: Product | null;
  tracking: {
    pixelId: string | null;
    conversionEvent: "Lead" | "Purchase" | "Purchase_Confirmed" | "Purchase_Delivered";
  };
};
```

تُرتَّب `images` حسب `position`؛ و`imageGap` هي المسافة بينها بالبكسل. ويُلتقط
العرض والارتفاع عند الرفع، لذا احجز الصندوق وتجنّب انزياح التخطيط.

`product` منتج كامل، لا بطاقة قائمة. ويمكن لنموذج الطلب استخدامه كما هو. ويكون
`null` عندما لا يكون المنتج عامًا بعد الآن؛ وفي هذه الحالة اعرض محتوى صفحة
الهبوط دون نموذج طلب.

صفحة هبوط مسوّدة أو مؤرشفة أو مجهولة تعيد `null`. أعد التوجيه إلى الصفحة
الرئيسية بدلًا من عرض طريق مسدود.

`tracking` الصفحة محلول مسبقًا. استخدم ذلك البكسل والحدث، لا بكسل المتجر
الافتراضي، عندما تطلق صفحة الهبوط حدث المتصفح.

## مستند الصفحة المحفوظ

يقرأ القالب القابل للتحرير مستند تركيب المتجر بـ`pageData.get(surface)`:

```ts
const document = await store.pageData.get("home");
```

شكل النقل فضفاض عمدًا:

```ts
type PageDocumentPayload = {
  version: number;
  surface: string;
  sections: unknown[];
  [key: string]: unknown;
};
```

تبقى `sections` من نوع `unknown[]` حتى يصل مستند أحدث إلى قالبك دون تغيير.
ومعنى القسم ينتمي إلى مخطط القالب. حلّله بـ`parsePageData` من
[`@wocart/theme`](/ar/sdk/theme)؛ ولا تحوّله إلى نوع القسم المحلي لديك.

```ts
import { parsePageData } from "@wocart/theme";

const parsed = parsePageData(document);
```

مع تعيين `theme` على العميل، يعيد الخادم مستند ذلك القالب للسطح. وبدونه، يعيد
الخادم أحدث مستند محفوظ للسطح. والمتجر بلا مستند محفوظ يعيد `null`؛ اعرض القيمة
الافتراضية التي تشحنها.

<Callout type="info" title="جهة القراءة فقط">
مستند الصفحة يكتبه CodFlow Studio، لا واجهة المتجر هذه. ولا يوجد في هذا
المستودع نقطة نهاية لكتابة القوالب. اقرأ `pageData`، واعرضه، واحفظ عقد تحرير
قالبك في `@wocart/theme`.
</Callout>

## قائمة تحقق لعرض الصفحة

- صفحة المتجر تستخدم `pages.get` وتردّ بـ404 حقيقي على `null`.
- الصفحة القانونية تحل رابطها عبر `kind`، لا عبر slug مضمّن.
- القائمة تُعرض بشكل عودي عبر `children` ووطّن المسارات الداخلية فقط.
- صفحة الهبوط تستخدم `tracking` الخاص بها، لا `config.pixelId`.
- السطح القابل للتحرير يستخدم `pageData.get(surface)` و`parsePageData`.
- المستند المفقود يعرض افتراضي القالب، لا صفحة فارغة.
- ذاكرة المسار المؤقتة تدرك عدد مرات تغيّر كل من هذه.
