# إعداد المتجر واللغات

`config.get()` هي أول قراءة في معظم الصفحات. تعيد إعدادات المتجر العامة أو
`null` عندما يتعذر قراءتها.

```ts
import { getStore } from "../theme/store";

const store = getStore();
const config = await store.config.get();

if (config === null) {
  return new Response("Store unavailable", { status: 503 });
}
```

إعدادات `null` تعني فشلًا حقيقيًا، لا متجرًا فارغًا. استخدم تخطيطك البديل أو
صفحة خطأ؛ ولا تخترع اسم متجر وعملة وتكمل وكأن القراءة نجحت.

## ماذا تحتوي الإعدادات

| المجموعة | الحقول | استخدمها في |
| --- | --- | --- |
| الهوية | `name`، `domain`، `logoUrl`، `themeId` | عنوان الصفحة والترويسة والمشاركة |
| العلامة | `primaryColor`، `accentColor`، `bgColor`، `fontFamily` | قيم قوالب قديمة؛ راجع الملاحظة أدناه |
| اللغات | `lang`، `locale`، `locales` | `<html lang>` و`dir` والمبدّل والروابط |
| العملة | `currency`، `currencySymbol` | `formatMoney` |
| SEO | `metaTitle`، `metaDescription`، `ogImage` | بيانات رأس الصفحة |
| الميزات | `reviewsEnabled`، `cartEnabled`، `otpEnabled`، `turnstileEnabled`، `turnstileSiteKey` | هل تعرض سطحًا؛ ومفتاح الودجة العام |
| السلة | `freeShippingThreshold`، `cartShippingMode` | للنص والعرض فقط؛ وعرض السعر يملك الرسوم |
| إتمام الطلب | `checkoutForm` | الحقول التي تعرضها والحقول المطلوبة |
| التتبع | `pixelId`، `conversionEvent` | تثبيت بكسل Meta واختيار الحدث |
| الصفحات | `pages` | روابط التذييل والموافقة |
| قانوني | `legalContact` | بيانات الاتصال العامة ومدة التوصيل |
| WhatsApp | `whatsapp` | إعدادات المشغّل ومفاتيح الأسطح |
| القالب | `themeSettings`، `contentOverrides` | القوالب القابلة للتحرير |

<Callout type="caution" title="الألوان في الإعدادات هي الطريقة القديمة">
`primaryColor` و`accentColor` و`bgColor` و`fontFamily` و`announcementBar`
قيم مهجورة حُفظت قبل إعدادات القالب. القالب القابل للتحرير يعلن ألوانه
وخطه وإعلانه في `defineTheme({ settings })` ويقرأ `themeSettings`. لا تبنِ
قالبًا جديدًا على الحقول المهجورة.
</Callout>

## مفاتيح الميزات

اعرض الميزة فقط عندما يملكها المتجر:

```astro
---
const { cartEnabled, reviewsEnabled, otpEnabled, turnstileSiteKey } = config;
---

{cartEnabled && <CartDrawer />}
{reviewsEnabled && <ProductReviews productId={product.id} />}
{otpEnabled && <OtpStep />}
{turnstileSiteKey && <div class="cf-turnstile" data-sitekey={turnstileSiteKey} />}
```

المتجر الذي لديه `cartEnabled: false` يجب ألا يرسل أي وسوم HTML للسلة. هذا ليس
تجميليًا: المفتاح هو مسار التراجع عن ميزة السلة.

وتنطبق القاعدة نفسها على المراجعات وOTP وودجة WhatsApp. توجد إعداداتها
ليتمكن المتجر من إيقاف السطح دون نشر.

## سياسة إتمام الطلب

`checkoutForm` هي سياسة نموذج التاجر، محلولة مسبقًا:

```ts
type CheckoutFormPolicy = {
  address: "required" | "optional" | "hidden";
  notes: "optional" | "hidden";
  email: "required" | "optional" | "hidden";
  deliveryOptions: { home: boolean; stopDesk: boolean };
  customFields: Array<{
    id: string;
    label: string;
    type: "text" | "textarea" | "number" | "select";
    required: boolean;
    options?: string[];
  }>;
};
```

اقرأها؛ ولا تعد تقريرها. خصوصًا:

- `hidden` تعني عدم عرض أي input، لا input معطّلًا أو فارغًا.
- `customFields` يكتبها التاجر. اعرض `label` كنص، وليس HTML أبدًا.
- أرسل الإجابات في `customFieldResponses`، بمفتاح `id` الذي ينشئه الخادم
  للحقل.
- يتحقق الخادم من السياسة نفسها عند إنشاء الطلب. ولا يستطيع اختصار في
  جانب العميل جعل حقل مطلوب اختياريًا.

```ts
const answers = config.checkoutForm.customFields.map((field) => ({
  id: field.id,
  value: formData.get(`custom:${field.id}`)?.toString() ?? "",
}));
```

يقبل إجراء الطلب حقل JSON واحدًا لهذه الإجابات، ليتمكن التاجر من إضافة حقل
مخصص دون نشر القالب.

## اللغات

للمتجر لغة أساسية (`lang`) وقائمة لغات منشورة (`locales`):

```ts
const config = await getStore().config.get();

config?.locales;
// [
//   { code: "ar", nativeName: "العربية", direction: "rtl" },
//   { code: "fr", nativeName: "français", direction: "ltr" },
// ]
```

تُرتَّب `locales` بالأساسية أولًا. وهي المرجع الوحيد للغات الموجودة؛ لا تضع
قائمة لغات ثابتة في قالبك.

تعيد `servedLanguage(config, code)` كائن اللغة لـ `<html lang>` و`dir`:

```astro
---
import { servedLanguage } from "@wocart/storefront";

const language = servedLanguage(config, config.locale);
---
<html lang={config.locale} dir={language?.direction ?? "ltr"}>
```

### شكل URL

اللغة الأساسية بلا بادئة. وكل لغة منشورة أخرى لها بادئة:

```text
/products/robe          primary (Arabic, for example)
/fr/products/robe       French
/ar/products/robe       301 to /products/robe
```

الدوال المساعدة التي تنفذ ذلك نقية:

```ts
import {
  alternateLinks,
  localeRouting,
  localizeHref,
  resolveLocalePath,
} from "@wocart/storefront";

const routing = localeRouting(config);

resolveLocalePath("/fr/products/robe", routing);
// { kind: "page", locale: "fr", pathname: "/products/robe" }

localizeHref("/products/robe", "fr", routing);
// "/fr/products/robe"

alternateLinks("/products/robe", routing, "https://shop.example");
// hreflang entries, primary first, plus x-default
```

لا تعامل `resolveLocalePath` المقطع الأول كلغة إلا إذا كان المتجر ينشرها.
والبادئة المجهولة مسار عادي وتُرجع 404 طبيعيًا.

### عميل واحد لكل لغة

يترجم الخادم نص التاجر. اطلب اللغة عبر العميل؛ ولا تترجم أسماء المنتجات في
المتصفح.

```ts
const primaryClient = getStore();
const primaryConfig = await primaryClient.config.get();

const routing = localeRouting(primaryConfig!);
const path = resolveLocalePath(Astro.url.pathname, routing);
if (path.kind === "redirect") return Astro.redirect(path.location, 301);

const client =
  path.locale === routing.primary ? primaryClient : getStore(path.locale);
const config = (await client.config.get()) ?? primaryConfig;
```

احتفظ بعميل واحد لكل لغة. فلكل عميل إعداداته وفئاته وبلدياته المخزنة.

إذا توقف المتجر عن نشر اللغة المطلوبة، تعود الإعدادات باللغة الأساسية.
وتخبرك `config.locale` باللغة التي وصلت فعلًا؛ فأعد التوجيه إذا لم تعد
تطابق URL.

### الروابط والبدائل

يجب أن يمر كل رابط داخلي عبر `localizeHref`، بما في ذلك الروابط التي تعيدها
القوائم:

```astro
<a href={localizeHref(item.href, config.locale, routing)}>{item.label}</a>
```

وفي الرأس، أخرج رابطًا بديلًا واحدًا لكل لغة منشورة:

```astro
---
const alternates = alternateLinks(Astro.url.pathname, routing, Astro.url.origin);
---
{alternates.map((link) => (
  <link rel="alternate" hreflang={link.hreflang} href={link.href} />
))}
```

## نص القالب وإعداداته

حقلان لا يحتويان بيانات إلا إذا أُنشئ العميل بمفتاح قالب:

```ts
const store = createStoreClient({
  serverUrl,
  apiKey,
  theme: "theme-00",
});

const config = await store.config.get();
config?.contentOverrides;
// { ar: { heroTitle: "..." }, fr: { heroTitle: "..." } }
config?.themeSettings;
// { primaryColor: "#...", layout: "wide" }
```

- `contentOverrides[locale]` هي تعديلات التاجر على نصوص قالبك في تلك اللغة.
  ادمج خريطة تلك اللغة فقط فوق نصوصك.
- `themeSettings` هي القيم التي حفظها التاجر كما هي. وفي قالب قابل للتحرير، 
  حلّها مقابل إعلان القالب عبر `resolveThemeSettings` من `@wocart/theme`.
- بدون `theme`، يكون الحقلان فارغين أو غائبين. ويمكن لواجهة متجر مخصصة
  بسيطة تجاهلهما واستخدام نصوصها وتنسيقاتها.

اقرأ [SDK القوالب](/ar/sdk/theme) إذا كنت تبني قالبًا قابلًا للتحرير.

## الصفحات والتفاصيل القانونية

تسرد `config.pages` الصفحات المنشورة التي اختارت الظهور في التذييل:

```ts
config.pages.map((page) => ({
  title: page.title,
  href: `/pages/${page.slug}`,
  kind: page.kind, // terms | privacy | refund | shipping | custom
}));
```

استخدم `kind` عندما تسمّي قاعدة صفحة — «أنت توافق على الشروط» يعني النوع
`terms`، لا مسارًا ثابتًا `/pages/terms`. فقد يعيد التاجر تسمية slug.

`config.legalContact` هو كتلة الاتصال العامة:

```ts
config.legalContact;
// {
//   contactEmail: "help@shop.example",
//   contactPhone: "0555 12 34 56",
//   deliveryMinDays: 2,
//   deliveryMaxDays: 5,
// }
```

تبقى `null` حتى يحفظ التاجر ملفًا قانونيًا. لا تخترع عنوانًا أو وعد توصيل
عندما تكون `null`.

## WhatsApp

`config.whatsapp` هي الودجة المحلولة، أو `null` عندما أوقفها التاجر. وعندما
توجد، تخبرك `showsWidgetOn(config.whatsapp.surfaces, pathname)` ما إذا كانت
مفعّلة على ذلك السطح.

```ts
import { showsWidgetOn } from "@wocart/storefront";

if (
  config.whatsapp &&
  showsWidgetOn(config.whatsapp.surfaces, Astro.url.pathname)
) {
  // Render the launcher and its prefill.
}
```

قواعد href والملء المسبق مشروحة في [المال والصور وWhatsApp وأحداث
Meta](/ar/sdk/storefront/presentation).
