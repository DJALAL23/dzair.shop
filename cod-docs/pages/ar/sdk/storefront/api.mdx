# واجهة API العامة

خريطة منظّمة لـ `@wocart/storefront` 1.19.0.
[المرجع المولَّد](/sdk/storefront/reference/README) يحوي كل التوقيعات؛ وهذه
الصفحة تجمع الواجهة حسب نقطة الدخول وتوضح ما يعمل وأين.

```sh
npm install @wocart/storefront zod
```

| الاستيراد | يعمل في | يحوي |
| --- | --- | --- |
| `@wocart/storefront` | المتصفح والخادم | الأنواع، مخططات Zod، أدوات المال والصور، المسارات، اللغات، السلة، OTP، الجغرافيا، الهاتف، الكوبونات وأحداث Meta |
| `@wocart/storefront/server` | الخادم فقط | `createStoreClient`، ونوع الخطأ، والمعاينة وإعادة التحقق |
| `@wocart/storefront/astro` | الخادم فقط | مسارات من نفس الأصل، والبروكسي، ومحرّك الطلب، ووسيط PRG |
| `@wocart/storefront/review-media` | المتصفح فقط | تصغير الصور وتسجيل الصوت لنموذج مراجعة |

<Callout type="caution" title="حدّ واحد، تحرسه المراجعة">
نقطة الدخول الجذرية لا تبني أي مخطط عند الاستيراد في الوحدات التي يستخدمها
المتصفح، لكنها تصدّر مخططات — واستيراد `ProductSchema` في سكربت صفحة يرسل Zod
إلى كل متسوّق. كود المتصفح يستورد الأدوات والأنواع؛ والتحقق يبقى على الخادم حيث
تدخل البيانات.
</Callout>

## المال والصور والعرض

| التصدير | ما يفعله |
| --- | --- |
| `formatMoney(amount, options)` | تنسيق مال المتجر؛ و`options` هو `{ symbol, locale }` |
| `optimizeImage(url, { width, height?, quality?, format?, fit? }, mediaDomain?)` | عنوان وسائط بمقاس جديد، أو الأصل إذا لم يكن عنوان وسائط |
| `generateSrcSet(url, baseWidth, baseHeight, mediaDomain?)` | `srcset` بثلاث دقّات: 1× و1.5× و2× للمقاس المعطى |
| `mediaUrl(key, mediaDomain?)` | **مفتاح** وسائط → عنوان، أو `null` بلا نطاق |
| `mediaImageUrl(src, params, mediaDomain?)` | عنوان وسائط مع معاملات تغيير المقاس |
| `createImageHelpers(mediaDomain)` | الأدوات نفسها مربوطة بنطاق واحد: `optimizeImage`، `generateSrcSet`، `IMAGE_SIZES`، `getCardImage` … `getLogoImage` |
| `mediaImageSrcset(src, widths, { mediaDomain, ratio?, quality? })` | ‏`srcset` حسب العرض، كل مقاس يُغيَّر على نطاق الوسائط؛ و`null` خارجه |
| `pictureOf(image, mediaDomain?)` | صورة اختارها التاجر ← `{ src, alt, width, height, position }`، ونقطة التركيز في صورة `object-position` |
| `productImageSource(product)` | عنوان الصورة الممثّلة للمنتج — غلافه، ثم أول صورة في المعرض، ثم `null` |
| `getProductView(product)`, `getProductListView(products)` | السعر، والنسخة الافتراضية، ونسبة الخصم، وحالة المخزون — مشتقة لا مخمّنة |
| `productMeta(product)`, `SEO_TEXT_LIMITS` | عنوان المنتج ووصفه لمحركات البحث: ما كتبه التاجر، وإلا فاسمه ووصفه كنص عادي |
| `productStructuredData(product, { url, storeName? })`, `jsonLd(value)` | كائن `Product` الخاص بـschema.org، ونص script من نوع JSON-LD لا يمكنه أن يُنهي الـscript أبدًا |
| `canonicalUrl(origin, { pathname, locale, routing }, search?)` | العنوان المرجعي للصفحة: مسارها بلغتها وصفحة القائمة، ولا شيء غير ذلك |
| `productTags(product)` | وسوم المنتج كقائمة، أيًّا كان الشكل المقروء |
| `getOfferTierView(tier)`, `getQuantityTierViews(tiers)` | شرائح السعر حسب الكمية للعرض |
| `initialVariant(variants)`, `optionStates(...)`, `pickOption(...)`, `variantFor(...)` | اختيار النسخة كآلة حالات |
| `buildWhatsAppHref(baseHref, text)`, `resolvePrefillText(params)`, `stripTrackingParams(text)`, `truncateAtWordBoundary(text, max)` | عنوان مشغّل WhatsApp ونصّه المبدئي المحدود |
| `MAX_RESOLVED_PREFILL_LENGTH`, `PREFILL_TOKENS` | حدّ النص المبدئي ورموزه |
| `META_CURRENCY`, `buildMetaViewContentPayload`, `buildMetaProductPayload`, `buildMetaAddToCartPayload`, `buildMetaInitiateCheckoutPayload`, `createMetaPixelTracker` | أحداث Meta في المتصفح بعملة المنصّة ومعرّفات المحتوى |

## أين تعيش الصفحة

| التصدير | ما يفعله |
| --- | --- |
| `STOREFRONT_PAGE_PATHS` | مسار كل نوع صفحة: `/products/:handle`، `/category/:slug`، `/collections/:handle`، `/pages/:slug`، `/lp/:slug`، `/checkout`، `/thank-you`, `/track-order` |
| `storefrontPath(type, params?)` | يبني مسارًا — ويرفع خطأً إذا نقص معامل مطلوب |
| `matchStorefrontPath(pathname)` | أي نوع صفحة يكونه المسار، مع معامله مفكوك الترميز، أو `null` |
| `showsWidgetOn(surfaces, pathname)` | هل يخصّ أداة WhatsApp الخاصة بالتاجر هذا المسار |
| `STOREFRONT_ROUTES` | **مهجور.** استخدم `STOREFRONT_PAGE_PATHS` مع الدالتين أعلاه |
| `servedLanguage(config, code?)`, `localeRouting(config)`, `resolveLocalePath(pathname, routing)`, `localizeHref(href, locale, routing)`, `alternateLinks(pathname, routing, origin)` | روابط مسبوقة باللغة، وفق نموذج المجلدات الفرعية في Shopify |

| `addedLines(before, after)` | ما أضافته الإضافة إلى السلة — لحدث `AddToCart`؛ وفارغ حين لا يبقى في السلة مكان |
| `createOtpMachine(...)`, `createOtpTransport(...)`, `mapOtpResponse(...)`, `otpTransportFailure(...)` | التحقق من الهاتف: الحالات، النقل، تحويل الأجوبة، وفشل النقل |

| `couponRefusalTone(reason)`, `COUPON_REFUSAL_REASONS`, `COUPON_HINT_REASONS` | هل رفض الرمز تلميح بشأن السلة أم رفض للرمز نفسه |
| `isOrderNumber(value)`, `ORDER_NUMBER_PATTERN` | شكل رقم الطلب (`ORD-20261023-0042`) |
| `REVIEW_REFUSAL_CODES`, `REVIEW_TEXT_LIMITS` | كل رفض قد تواجهه المراجعة، وأطوال عنوانها ونصها |
| `PRODUCT_SORTS`, `SHOPPER_ORDER_STAGES`, `SHOPPER_ORDER_JOURNEY`, `DEFAULT_COLLECTION_HANDLES` | ترتيبات القائمة؛ ومراحل الطلب والمسار الذي يعرضه شريط التقدم؛ والمجموعات التي يبدأ بها كل متجر |
| `isWilayaId(value)`, `WILAYAS`, `ALGERIA_COMMUNES`, `communesForWilaya(id)`, `normalizeAlgerianPhone(phone)`, `toLocalAlgerianMobile(phone)` | أدوات جغرافيا وهاتف، بلا شبكة |
| `couponFromUrl(url)`, `couponRefusalOf(result)`, `COUPON_URL_PARAM`, `COUPON_NOT_APPLICABLE` | رمز كوبون يحمله كائن `URL`، والرفض الذي تحمله نتيجة كتابة |
| `STOREFRONT_OPERATIONS`, `STOREFRONT_RETRY_POLICIES` | أسماء العمليات التي يحملها كل خطأ، وسياسة إعادة المحاولة لكل منها |

## العميل، فضاءً بفضاء

`createStoreClient(scope)` يعيد هذه الفضاءات؛ وهو للخادم فقط ويأخذ
`{ serverUrl, apiKey, theme?, locale?, onError?, readTimeoutMs? }`.

| الفضاء | الدوال | ما يعيده استدعاء فاشل |
| --- | --- | --- |
| `config` | `get()` | `null` |
| `products` | `get(handle)`, `list(filters?)`, `page(filters?)`, `search(text, filters?)` | `null` / `[]` / `{ items: [], hasNext: false, total: null }` |
| `products.reviews` | `list(productId, pagination?)`, `eligibility(input)`, `upload(input)`, `submit(input)` | `{ rows: [], total: 0 }` للقراءة، و`ClientResult` للكتابات |
| `collections` | `get(handle)` | `null` |
| `categories` | `list()` | `[]` |
| `pages` | `get(slug)`, `landing(slug)` | `null` |
| `menus` | `get(handle)` | `null` |
| `pageData` | `get(surface)` | `null` |
| `shipping` | `rates()`, `rate(wilayaId)` | `{}` / `null` |
| `geo` | `wilayas()`, `communes(wilayaId)` | `[]` |
| `cart` | `validate(items, options?)`, `quote(lines, options?)` | `ClientResult` |
| `orders` | `create(input)`, `tracking(orderId)`, `status(proof)`, `abandoned.upsert(input)`, `abandoned.convert(input)`, `otp.send(input)`, `otp.verify(input)` | `ClientResult` (و`tracking` يعيد `null`) |

عقد القراءة هو أهم وعد في الـ SDK: قراءة فاشلة تتراجع إلى قيمة فارغة وتُبلّغ عبر
`onError`، ولا ترفع استثناءً أبدًا. والكتابة تعيد `ClientResult` —
`{ success: true, data }` أو `{ success: false, domainError }` — لأن الرفض جواب
متوقّع لا استثناء.

## المخططات والأنواع

نقطة الدخول الجذرية تصدّر مخططات Zod التي يتحقق بها العميل، لسكربت أو مسار يحتاج
الشكل نفسه:

- **الكتالوج**: `ProductSchema`, `ProductListSchema`, `ProductImageSchema`,
  `ProductVariantSchema`, `OfferSchema`, `QuantityPricingSchema`,
  `CategorySchema`, `StoreCollectionSchema`, `StoreMenuSchema`,
  `StoreMenuItemSchema`.
- **المتجر**: `StoreConfigSchema`, `StorefrontLanguageSchema`,
  `StorePagePublicSchema`, `StorePageLinkSchema`, `StoreLegalContactSchema`,
  `CheckoutFormPolicySchema`, `CheckoutFormCustomFieldSchema`,
  `StoreWhatsAppWidgetSchema`, `LandingPageSchema`, `LandingPageImageSchema`,
  `PageDocumentPayloadSchema`.
- **التجارة**: `ShippingRatesSchema`, `WilayaRatesSchema`, `CommuneSchema`,
  `CartValidationSchema`, `CartValidationLineSchema`, `CartRewardSchema`,
  `CouponOutcomeSchema`, `CreatedOrderSchema`, `OrderTrackingSchema`,
  `ReviewSchema`, `ReviewMediaSchema`, `ReviewEligibilitySchema`,
  `ReviewUploadSchema`, `ReviewSubmitResultSchema`, `ReviewListEnvelopeSchema`,
  `OtpSendResultSchema`, `OtpVerifyResultSchema`, `IdResponseSchema`.
- **المدخلات**: `BasketSchema`, `BasketLineSchema`, `BasketLineInputSchema`,
  `AbandonedCheckoutInputSchema`, `AbandonedBasketLineSchema`,
  `ProductQuoteInputSchema`, `CartQuoteLinesSchema`, `DeliveryDestinationSchema`,
  `DeliverySelectionSchema`, `OtpProofSchema`, `OrderSchema`,
  `TrackingDecisionSchema`, `WilayaIdSchema`.

الأنواع التي يسمّيها القالب أكثر: `StoreConfig`, `StorefrontLanguage`, `Product`,
`ProductList`, `ProductDetail`, `Category`, `StoreCollection`, `StoreMenu`,
`StorePagePublic`, `LandingPage`, `CartValidation`, `CartQuoteOptions`,
`CreatedOrder`, `OrderTracking`, `Review`, `ReviewEligibility`, `Wilaya`,
`Commune`, `DomainError`, `ClientResult`, `StoreScope`, `ProductPage`,
`ProductView`, `BasketStore`, `OtpMachine`, `MetaPixelTracker`.

## `@wocart/storefront/server`

| التصدير | ما يفعله |
| --- | --- |
| `createStoreClient(scope)` | مصنع العميل الوحيد؛ يرفع خطأً عند البناء إذا كان `serverUrl` أو `apiKey` فارغًا |
| `StoreClient`, `ClientResult` | نوعه، ونوع نتيجة الكتابة |
| `StorefrontError`, `isStorefrontError(error)` | نوع الخطأ، وفحص التضييق |
| `readPreviewRequest(request, { publicKey, theme })`, `verifyPreviewToken(token, options)`, `previewConfig(config, draft)`, `previewResponseHeaders(claims)` | طلب معاينة المحرّر: ادّعاءات متحقَّق منها، وإعداد المسودة، وترويسات تُبعده عن أي ذاكرة تخزين |
| `REVALIDATE_PATH`, `readRevalidateRequest(request, options)` | مسار خطاف النشر (`/wocart-revalidate`) وطلبه المتحقَّق |
| `catalogPaths(client, config)`, `sitemapXml(paths, routing, origin)` | كل صفحة تدرجها خريطة الموقع، وخريطة الموقع بكل لغة منشورة |

## `@wocart/storefront/astro`

| التصدير | ما يفعله |
| --- | --- |
| `createStorefrontRoutes({ client })` | المسارات من نفس الأصل: `otpSend`, `otpVerify`, `cartValidate`, `abandonedUpsert`, `abandonedConvert`, `communes`, `reviewsList`, `reviewEligibility`, `reviewUpload`, `reviewSubmit`, `orderStatus` |

| `createProxyEndpoint(config)` | بروكسي عام من نفس الأصل لما لا تغطّيه المسارات أعلاه |
| `placeOrderInput` | قائمة مدخلات نموذج الطلب المسموحة (كائن Zod) |
| `executePlaceOrder(input, request, client)` | محرّك الطلب: قاعدة السلة أو المنتج، والإسناد، والجسم المُرسل |
| `collectForwardedHeaders(request)` | الترويسات التي يمرّرها المسار إلى الخادم |
| `runFormAction(...)`, `resolveActionRedirectDecision(...)` | وسيط post/redirect/get الذي يعرض النموذج المرفوض في مكانه |
| `resolveStoreRequest(request, options)`, `resolvePreviewStore(draft, options)` | أي متجر وأي لغة يعرضها الطلب، وإعادات التوجيه؛ ومتجر مسودة المحرر |

| `lookupOrder(input, request, client)`, `orderLookupInput` | بحث المتسوق عن طلبه لنموذج التتبّع، ونتيجته في بضع حالات |
| `PlaceOrderInput`, `PlaceOrderResult`, `PrgDecision`, `ActionDescriptor`, `ActionMiddlewareDeps`, `ProxyEndpointConfig`, `ProxyClientFn`, `AstroAPIContext`, `AstroAPIRoute`, `StorefrontApiRoute`, `StorefrontRoutes`, `StorefrontRoutesOptions` | الأنواع التي تأخذها هذه الدوال وتعطيها |

## `@wocart/storefront/review-media`

| التصدير | ما يفعله |
| --- | --- |
| `prepareReviewPhoto(photo, options?, deps?)` | يصغّر الصورة إلى 1600 بكسل كحد أقصى ويعيد ترميزها (WebP وإلا JPEG)؛ وإعادة الترميز تُسقط EXIF |
| `createReviewSession({ routes, attempts? }, deps?)` | حوار نموذج المراجعة كله: إيجاد الطلب، وإرسال كل ملف مع التقدّم وإعادة المحاولة، ثم الإرسال |
| `photoTargetSize(width, height, maxEdge)` | المقاس الذي تُرسم به الصورة |
| `createVoiceRecorder(options, deps?)`, `canRecordVoice(deps?)` | تسجيل ملاحظة صوتية بمعدّل بت منخفض، ويتوقف عند حدّ المتجر |
| `pickVoiceMimeType(isTypeSupported)`, `VOICE_MIME_TYPES` | الحاوية/الترميز الذي يدعمه المتصفح، بترتيب الأفضلية |
| `PhotoOptions`, `PhotoDeps`, `RecordedVoice`, `VoiceRecorderOptions`, `VoiceRecorder`, `VoiceDeps` | أنواع الخيارات والحقن |

كل واحدة تأخذ تبعيات المتصفح كوسيط أخير اختياري، فتعمل في اختبار بـ canvas أو
مسجّل بديل.

<Callout type="caution" title="ما ليس عامًّا">
المسارات العميقة `dist/…` و`src/…` قد تتغيّر في أي إصدار. وقلب العميل الداخلي
وذاكراته ونقله ليست جزءًا من العقد؛ وإذا نقص شيء في الواجهة العامة فهو تغيير في
الـ SDK لا استيراد عميق.
</Callout>

## النسخة

يتبع هذا الدليل `@wocart/storefront` 1.19.0 مع `zod` 4.x (وهو peer). ثبّت نسخًا
محددة واقرأ `CHANGELOG.md` للحزمة قبل الترقية — راجع
[اختبار واجهة متجر](/sdk/storefront/testing#compatibility).
