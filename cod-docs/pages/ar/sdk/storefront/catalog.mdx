# المنتجات والمجموعات

يقدّم الكتالوج أربع طرق للقراءة:

| القراءة | تعيد | استخدمها في |
| --- | --- | --- |
| `products.list(filters)` | `ProductList[]` | الشبكات والأشرطة ونتائج البحث |
| `products.page(filters)` | `{ items, hasNext }` | صفحات كتالوج مقسّمة إلى صفحات |
| `products.get(handle)` | `Product \| null` | صفحة منتج |
| `collections.get(handle)` | `StoreCollection \| null` | صفحة مجموعة |

`ProductList` شكل بطاقة مختصر. أما `Product` فهو شكل التفاصيل الكامل مع
المتغيّرات والصور والعروض وأسعار الكمية.

## عرض المنتجات

```ts
const products = await store.products.list({
  collection: "best-sellers",
  limit: 8,
});
```

عوامل التصفية هي:

| عامل التصفية | ما يفعله |
| --- | --- |
| `categoryId` | المنتجات في تلك الفئة |
| `collection` | المنتجات في تلك المجموعة، بترتيب التاجر |
| `onSale` | المنتجات التي يقل سعرها عن سعر المقارنة |
| `limit` | حدّ من جهة الخادم؛ ويقصّ الخادم أي قيمة أكبر |
| `offset` | تخطَّ هذا العدد من المنتجات |

لا يزال `featured` موجودًا لكنه مهجور. استخدم `collection: "featured"`؛ فمجموعة
التاجر المميزة هي القائمة نفسها، دون علم خاص.

استخدم `products.page` عندما تحتاج الصفحة إلى رابط «التالي»:

```ts
const page = await store.products.page({ limit: 24, offset });

if (page.hasNext) {
  // link to ?offset=24
}
```

يطلب `page` من الخادم صفًا إضافيًا بعد الصفحة ويقتطعه، لذا يكون `hasNext`
دقيقًا دون استعلام عدّ. والقراءة الفاشلة تعني صفحة أخيرة فارغة، بالطريقة نفسها
التي يتدهور بها `list`.

المجموعة أو الفئة المجهولة لا تسرد شيئًا. لا تعامل ذلك كخطأ في صفحة كتالوج؛
اعرض الحالة الفارغة.

## بطاقات المنتج

يحمل `ProductList` ما تحتاجه البطاقة:

```ts
type ProductList = {
  id: string;
  name: string;
  handle: string;
  price: number;
  compareAtPrice: number | null;
  currency: string;
  coverImage: ProductImage | null;
  reviewStats: { avgRating: number; reviewCount: number } | null;
  type: "PHYSICAL" | "DIGITAL";
  inventory: number;
  trackInventory: boolean;
  lowStockThreshold: number;
  // …status and visibility fields the server already filtered on
};
```

القائمة مفلترة مسبقًا إلى ما يجوز للمتسوّق رؤيته. لا تعِد التحقق من `status`
أو `visibility` في المتصفح، ولا تستدعِ حقل إدارة داخليًا.

لا تحتوي القائمة على بيانات المتغيّرات. وإذا احتاجت بطاقة إلى «ابتداءً من
2,500 دج» لمنتج متغيّر، فإن `ProductList.price` هو السعر التمثيلي الذي يرسله
الخادم؛ والسعر الدقيق يأتي من تفاصيل المنتج.

### الصورة

غالبًا ما تكون `coverImage` مساوية لـ`null`: فقد يرفع التاجر معرضًا دون اختيار صورة غلاف.
استخدم `productImageSource`، الذي يعود إلى أول صورة صالحة في المعرض:

```ts
import { getCardImage, productImageSource } from "@wocart/storefront";

const src = productImageSource(product);
const cardUrl = src ? getCardImage(src, mediaDomain) : null;
```

اعرض عنصرًا بديلًا عندما تكون `cardUrl` مساوية لـ`null`. لا تعرض `<img>` مكسورًا بـ`src`
فارغ.

## تفاصيل المنتج

تُقرأ صفحة المنتج بواسطة **handle**، وهو مقطع URL العام:

```astro
---
import { formatMoney, getProductView } from "@wocart/storefront";
import { getStore } from "../../theme/store";

const store = getStore();
const config = await store.config.get();
if (!config) return new Response("Store unavailable", { status: 503 });

const product = await store.products.get(Astro.params.handle!);
if (!product) return Astro.rewrite("/404");

const view = getProductView(product);
---
<article>
  <h1>{product.name}</h1>
  <p>{formatMoney(view.basePrice, { symbol: config.currencySymbol, locale: config.locale })}</p>
  {view.hasDiscount && <p>Save {view.discountPct}%</p>}
  {view.isOutOfStock && <p>Out of stock</p>}
</article>
```

تعيد `getProductView` أول متغيّر قابل للبيع وحالة المخزون للمنتج:

```ts
type ProductView = {
  defaultVariant: ProductVariant | null;
  basePrice: number;
  comparePrice: number | null;
  hasDiscount: boolean;
  discountPct: number;
  isOutOfStock: boolean;
  isLowStock: boolean;
};
```

بالنسبة إلى منتج متغيّر، `product.inventory` ملخّص على مستوى المنتج. تحقق من
`variant.inventory` قبل السماح للمتسوّق بطلب متغيّر محدد.

## المتغيّرات

يحمل المنتج المتغيّر:

```ts
product.hasVariants; // true
product.variantOptions;
// [
//   { name: "Size", values: [{ value: "M", hexColor: null }, …] },
//   { name: "Color", values: [{ value: "Red", hexColor: "#c00" }, …] },
// ]
product.variants;
// [{ id, variations: { Size: "M", Color: "Red" }, price, inventory, … }]
```

تحافظ الدوال المساعدة على دقة المنتقي:

```ts
import {
  initialVariant,
  optionStates,
  pickOption,
  variantFor,
} from "@wocart/storefront";

let selection = initialVariant(product)?.variations ?? {};
const states = optionStates(product, selection);

const picked = pickOption(product, selection, "Size", "L");
selection = picked.selection;

const variant = variantFor(product.variants, selection);
```

يبدأ `initialVariant` بالقيمة الافتراضية للتاجر عندما يمكن بيعها، وإلا فعلى
أول متغيّر قابل للبيع. وتعيد `pickOption` دائمًا متغيّرًا موجودًا، أو تترك
الاختيار دون تغيير. وتميّز `optionStates` القيمة على النحو التالي:

- `available` — يوجد متغيّر قابل للبيع يحملها مع الخيارات الأخرى؛
- `sold_out` — المتغيّر موجود لكن لا مخزون له؛
- `unavailable` — لا يجمع أي متغيّر تلك القيمة مع الخيارات الأخرى.

اعرض قيم `unavailable` معطّلة، وقيم `sold_out` كغير متاحة بشكل ظاهر. ولا يزال
الخادم يتحقق من المتغيّر المُرسل.

## الأسعار والعروض

الأسعار أعداد صحيحة بعملة المتجر (دج). نسّقها بـ`formatMoney`؛ ولا تقسم على 100
أبدًا إلا إذا أخبرت بذلك بيانات عملة متجرك.

يمكن أن يحمل المنتج ثلاثة أنواع من العروض الترويجية:

| النوع | الحقل | المعنى |
| --- | --- | --- |
| سعر المقارنة | `compareAtPrice` | سعر مرجعي مشطوب |
| أسعار الكمية | `quantityPricing.tiers` | شرائح «2 مقابل 3,500 دج» |
| اشترِ X واحصل على Y | `offers` | هدية أو توصيل مجاني |

### شرائح الكمية

```ts
import { getQuantityTierViews } from "@wocart/storefront";

const tiers = product.quantityPricing
  ? getQuantityTierViews(product.quantityPricing, view.basePrice)
  : [];
```

تعطي كل شريحة `quantity` و`price` و`perUnit` و`savingsAmount` و`savePct`
و`freeShipping`. وهذه قيم عرض. أما المبلغ الإجمالي الذي يدفعه المتسوّق فهو
دائمًا عرض سعر السلة من الخادم.

### اشترِ X واحصل على Y

```ts
import { getOfferTierView } from "@wocart/storefront";

const offer = product.offers[0];
if (offer) {
  const tile = getOfferTierView(offer, view.basePrice, view.comparePrice);
  // tile.price, tile.savingsAmount, tile.isFreeShipping
}
```

يمكن أن يكون العرض `free` (هدية) أو `free_shipping`. ويقرر الخادم ما إذا كانت
الكمية مؤهلة ويضيف المكافأة. وإذا اختار المتسوّق شريحة محددة، فضع `offerId`
الخاص بها على سطر السلة؛ فالشريحة المشتركة تُسعَّر عندئذ كما اختار المتسوّق.

<Callout type="info" title="لا تحسب العرض الترويجي">
قد تعرض صفحة «اشترِ 2 واحصل على 1 مجانًا». ويجب ألا تضيف الهدية بنفسها، أو
تخصم خصمًا، أو تلغي التوصيل. أرسل `offerId` المختار واترك `cart.validate` /
`cart.quote` يردّان بالسطور المسعّرة والمكافآت والإجمالي.
</Callout>

## الفئات

تعيد `categories.list()` قائمة مسطّحة ومرتّبة. ابنِ الشجرة من `parentId`؛ ولا
يعيد SDK أبناءً متداخلين.

```ts
const categories = await store.categories.list();

const roots = categories.filter((category) => category.parentId === null);
const childrenOf = (id: string) =>
  categories.filter((category) => category.parentId === id);
```

تُقرأ صفحات الفئة بـ`slug`:

```astro
---
const category = (await store.categories.list()).find(
  (item) => item.slug === Astro.params.slug,
);

if (!category) return Astro.rewrite("/404");

const products = await store.products.list({
  categoryId: category.id,
  limit: 24,
});
---
```

تُخزَّن `categories.list()` مؤقتًا طوال عمر العميل بعد قراءة ناجحة. وتظهر
إعادة تسمية الفئة في عرض الخادم التالي، لا في عميل قديم.

## المجموعات

المجموعة قائمة ينظّمها التاجر ولها صفحتها الخاصة:

```astro
---
const collection = await store.collections.get(Astro.params.handle!);
if (!collection) return Astro.rewrite("/404");

const products = await store.products.list({
  collection: collection.handle,
  limit: 24,
});
---
<h1>{collection.title}</h1>
{collection.description && <p>{collection.description}</p>}
```

تعيد `collections.get` الاسم والوصف؛ وتأتي المنتجات من
`products.list({ collection })` بترتيب التاجر. ويُترجم كليهما عندما تكون لغة
العميل منشورة.

## الأوصاف وSEO

يخبر `product.descriptionFormat` كيف تعرض الوصف:

- `"text"` — اعرضه كنص، مع الحفاظ على فواصل الأسطر.
- `"html"` — اعرضه بـ`set:html`.

`descriptionPlain` هي النسخة النصية فقط لأوصاف meta وأي مكان يكون فيه الترميز
خاطئًا. استخدمها في `<meta name="description">` وJSON-LD.

تحمل صفوف الفئة والمنتج `metaTitle` و`metaDescription` حيث توجد؛ والبدائل على
مستوى المتجر هي `config.metaTitle` و`config.metaDescription`.

## ما لا تغطيه هذه الصفحة

تعيش المراجعات في [المراجعات](/ar/sdk/storefront/reviews). وتوجد السلة وعرض سعر
الخادم في [السلة وعروض الأسعار](/ar/sdk/storefront/basket). وتوجد دوال
الصور والمال في [المال والصور وWhatsApp وأحداث
Meta](/ar/sdk/storefront/presentation).

لا توجد طريقة بحث نصي كامل عن المنتجات في هذا SDK. وإذا احتاجت واجهة المتجر
إلى بحث، فهي تحتاج نقطة نهاية على الخادم؛ لا تصنع واحدة وهمية بتنزيل الكتالوج
كله إلى المتصفح.
