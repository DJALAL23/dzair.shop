# التوصيل والجغرافيا

للتوصيل طبقتان:

- **البيانات المرجعية** — الولايات الـ58 وبلدياتها.
- **المال** — أسعار التاجر، وفوقهما عرض السعر من الخادم للوجهة التي اختارها
  المتسوق.

عرض السعر هو الرسم. وجدول الأسعار مجرد مساعدة للعرض حتى يجيب عرض السعر.

## الولايات

تحل `geo.wilayas()` من مجموعة بيانات مضمّنة مع SDK. ولا يُجرى أي طلب شبكة.

```ts
const wilayas = await store.geo.wilayas();

wilayas;
// [
//   { id: 1, name: "Adrar", nameAr: "أدرار" },
//   …
// ]
```

تضم القائمة ولايات الجزائر الـ58 بالترتيب الرسمي. وهي بيانات مرجعية ثابتة، لا
محتوى تاجر، لذا لا يترجمها المتجر.

تتحقق `isWilayaId(value)` من قيمة غير معروفة قادمة من نموذج أو URL:

```ts
import { isWilayaId } from "@wocart/storefront";

if (!isWilayaId(Number(input))) {
  return { field: "wilayaId", message: "Choose a wilaya." };
}
```

تقرأ المجموعة نفسها التي يقرأها النموذج، فلا يمكن أن يختلفا.

## البلديات

تعيد `geo.communes(wilayaId)` بلديات ولاية واحدة:

```ts
const communes = await store.geo.communes(16);

communes;
// [{ id: "c-16-001", name: "Alger Centre", nameAr: "الجزائر الوسطى" }, …]
```

يُخزَّن الاستدعاء لكل ولاية في العميل بعد قراءة ناجحة. ولا تُعِد الاستدعاء إلا
عندما تتغير الولاية.

الولاية المجهولة تحل إلى `[]`؛ والقراءة الفاشلة تحل أيضًا إلى `[]`. يبدوان
متطابقين، لذا يجب على واجهة ترى قائمة فارغة بعد ولاية صحيحة أن تعرض إعادة
المحاولة، لا «هذه الولاية بلا بلديات».

```ts
async function loadCommunes(wilayaId: number) {
  const communes = await store.geo.communes(wilayaId);
  if (communes.length === 0) {
    showCommuneRetry();
    return;
  }
  fillCommuneSelect(communes);
}
```

عندما تتغير الولاية، امسح البلدية المحددة قبل تحميل القائمة الجديدة. فمعرّف
بلدية من الولاية القديمة غير صالح في الولاية الجديدة.

## جدول الأسعار

تعيد `shipping.rates()` الرسم الافتراضي للتاجر لكل ولاية سعّرها:

```ts
const rates = await store.shipping.rates();

rates["16"]; // { home: 400, stopDesk: 250 }
```

تقرأ `rates()` و`rate(wilayaId)` الجدول الكامل من جديد في كل استدعاء؛ فالتجار
يغيّرون أسعار التوصيل ويتوقعون أن يعرضها العرض التالي. ولا يُخزَّنان.

`shipping.rate(16)` هو البحث نفسه لولاية واحدة، أو `null` عندما لا يكون لتلك
الولاية صف:

```ts
const rate = await store.shipping.rate(wilayaId);
const fee =
  rate === null
    ? null
    : deliveryType === "home"
      ? rate.home
      : rate.stopDesk;
```

غياب الصف يعني أن التاجر ليس لديه رسم افتراضي لتلك الولاية. ولا يعني دائمًا «لا
نوصل إليها»: فقد تنتج تسعيرة شركة التوصيل رسمًا لوجهة لا يغطيها الجدول
الافتراضي. استخدم عرض السعر للحكم.

<Callout type="caution" title="جدول الأسعار ليس إجمالي الطلب">
لا يحتوي جدول التاجر على سلة ولا حد للتوصيل المجاني ولا منطقة شركة توصيل.
والطلب يحتسب `CartValidation.delivery`، الذي يحسبه الخادم بالقواعد نفسها التي
يستخدمها عند إتمام الطلب. اعرض الجدول ما دام عرض السعر معلقًا، ثم استبدله.
</Callout>

## عرض السعر المعتمد

اطلب عرض سعر مع وجهة:

```ts
const result = await store.cart.validate(items, {
  destination: {
    wilayaId,
    communeId,
    deliveryType: "home",
  },
});

if (!result.success) return;

const delivery = result.data.delivery;
if (delivery?.available) {
  showFee(delivery.fee);
  showTotal(delivery.total);
} else if (delivery) {
  showNotDeliverable();
}
```

لا يكون `delivery` موجودًا إلا عند إرسال وجهة. وله شكلان:

```ts
type DeliveryQuote =
  | { available: true; fee: number; total: number }
  | { available: false; fee: null; total: null };
```

`available: false` يعني أن الخادم يرفض هذه الوجهة. عطّل زر الإرسال؛ ولا ترسل
الطلب آملًا قبوله.

`delivery.total` هو المبلغ الذي تعرضه بعد عرض السعر. وهو يشمل بالفعل رسم
التوصيل والمجموع الفرعي للسلة والمكافآت والكوبون.

### متى تطلب عرض السعر

اطلب عرض السعر من جديد كلما تغيّر أي مما يلي:

- الولاية؛
- البلدية؛
- التوصيل إلى المنزل أو إلى مكتب الاستلام؛
- كمية أحد البنود أو متغيّره؛
- الكوبون؛
- الهاتف، عندما يكون الكوبون محدودًا لكل عميل.

أخّر معالجة التغييرات (debounce) كي لا تؤدي كتابة رقم هاتف إلى إرسال عرض
سعر مع كل ضغطة مفتاح. اطلب عرض السعر عندما تكتمل الوجهة.

### التوصيل المجاني

يحمل عرض السعر `freeDelivery`:

```ts
result.data.freeDelivery;
// {
//   fromOffer: false,
//   threshold: 5000,
//   qualified: true,
//   remaining: 0,
// }
```

تتفوق `qualified` على جدول الأسعار. ولا تحتسب رسمًا لأن الجدول يقول ذلك بينما
يقول عرض السعر إن التوصيل مجاني.

### لا وجهة بعد

قبل أن يختار المتسوق ولاية، لا يوجد عرض سعر ولا إجمالي توصيل. وهذا ليس «0»
وليس «غير قابل للتوصيل»:

```ts
if (!destination) {
  showDeliveryCalculatedLater();
} else if (delivery?.available === false) {
  showNotDeliverable();
} else if (delivery?.available) {
  showFee(delivery.fee);
}
```

## قراءة عرض سعر في المتصفح

يمكن للصفحة أن تحمل ناتج `shipping.rates()` بصيغة JSON لسكربتها. وإذا كان
السكربت قد يكون بإصدار مختلف عن الصفحة، فاقرأ القيمة دون مخطط:

```ts
import { readShippingRates } from "@wocart/storefront";

const rates = readShippingRates(embeddedRates);
if (rates === null) {
  // Not a rate table: ignore it and wait for the quote.
}
```

تقبل `readShippingRates` ما يقبله مخطط الخادم بالضبط وتُسقط المفاتيح المجهولة.
وهي لا تُدخل Zod في حزمة المتسوق.

## قائمة تحقق للتوصيل

- تأتي قائمة الولايات من `geo.wilayas`، لا من مصفوفة منسوخة يدويًا.
- تغيير الولاية يمسح البلدية ويجلب القائمة الجديدة.
- قائمة بلديات فارغة بعد ولاية صحيحة تعرض إعادة المحاولة.
- لا يُعرض سعر التاجر إلا حتى يصل عرض السعر.
- الوجهة المكتملة تحصل دائمًا على عرض سعر.
- `delivery.available === false` تعطّل الإرسال.
- عرض سعر بتوصيل مجاني يتجاوز الجدول.
- `delivery.total` هو الرقم المعروض كمبلغ مستحق.
