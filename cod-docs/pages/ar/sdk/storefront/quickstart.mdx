# البدء السريع

تبني هذه الصفحة أصغر وصلة متكاملة لواجهة المتجر: عميل واحد على الخادم فقط،
وقائمة منتجات، وصفحة منتج تعيد 404 حقيقيًا. إنه كود Astro عادي؛ وSDK يوفّر
بيانات المتجر.

## ما تحتاجه

- مشروع Astro 7 مع تفعيل العرض على الخادم.
- أصل API لمتجر ومفتاح API للمتجر.
- `@wocart/storefront` و`zod` مثبّتان.

```bash
npm install @wocart/storefront zod
```

<Callout type="caution" title="لا تضع المفتاح في المتصفح">
مفتاح API الخاص بالمتجر سرّ خادم. مكانه في متغير بيئة على الخادم و
`@wocart/storefront/server`. يجب ألا يكون أبدًا متغير `PUBLIC_*`، ولا قيمة
تُعرض في HTML، ولا وسيطًا يُمرّر إلى دالة في المتصفح.
</Callout>

## 1. أضف قيم البيئة

تحتاج واجهة المتجر إلى قيمتين على الخادم:

| الاسم | ما هو |
| --- | --- |
| `COD_SERVER_URL` | أصل API الخاص بالمتجر، مثل `https://api.my-store.com` |
| `STORE_API_KEY` | مفتاح API الخاص بالمتجر |

مع مخطط البيئة في Astro، أعلن القيمتين كقيم خادم. المفتاح سرّ؛ ويمكن أن يكون
الأصل سرًّا أيضًا، لأن كود الخادم وحده يحتاجه.

```js
// astro.config.mjs
import { defineConfig, envField } from "astro/config";

export default defineConfig({
  env: {
    schema: {
      COD_SERVER_URL: envField.string({ context: "server", access: "secret" }),
      STORE_API_KEY: envField.string({ context: "server", access: "secret" }),
    },
  },
});
```

لا يقرأ SDK أي متغير بيئة بنفسه. أنت تمرّر القيم إليه، ما يبقي العميل نفسه
قابلًا للاستخدام في Astro أو Worker أو اختبار أو سكربت.

## 2. أنشئ وحدة خادم واحدة

أبقِ إنشاء العميل في ملف واحد. إذا كان الأصل أو المفتاح خاطئًا، فهذا هو الملف
الذي يجب فحصه؛ ولا يجب أن تبني أي صفحة عميلها الخاص.

```ts
// src/theme/store.ts
import { createStoreClient } from "@wocart/storefront/server";
import { COD_SERVER_URL, STORE_API_KEY } from "astro:env/server";

export function getStore(locale?: string) {
  return createStoreClient({
    serverUrl: COD_SERVER_URL,
    apiKey: STORE_API_KEY,
    ...(locale ? { locale } : {}),
    onError: (error) => {
      console.warn(`[store] ${error.operation} failed: ${error.code}`);
    },
  });
}
```

هذا هو الشكل نفسه الذي يستخدمه Theme-00 في `src/theme/sdk.ts`. يُنشأ العميل مع
كل استدعاء، فلا يمكن لطلب أن يحتفظ بعمل طلب آخر المعلّق. العميل الواحد يخدم
متجرًا واحدًا ولغة واحدة؛ لا تشاركه بين متاجر.

خيار `locale` مخصّص لقراءة نصوص التاجر بلغة منشورة أخرى، وهو اللغة التي يُسجَّل
بها الطلب الذي ينشئه العميل، فتُكتب رسائل الزبون بها. احذفه لاستخدام اللغة
الأساسية للمتجر. تشرح صفحة [إعداد المتجر واللغات](/ar/sdk/storefront/config)
الباقي.

## 3. اعرض قائمة منتجات

تنتهي القراءة إلى قيمة فارغة عندما يتعذّر إكمالها. الكتالوج الفارغ حالة يجب
تصميمها، لا استثناء يجب التقاطه.

```astro
---
// src/pages/products/index.astro
import { formatMoney } from "@wocart/storefront";
import { getStore } from "../../theme/store";

const store = getStore();
const [config, products] = await Promise.all([
  store.config.get(),
  store.products.list({ limit: 12 }),
]);
---
<html lang={config?.lang ?? "ar"}>
  <body>
    <h1>Products</h1>

    {products.length === 0 ? (
      <p>No products are available right now.</p>
    ) : (
      <ul>
        {products.map((product) => (
          <li>
            <a href={`/products/${product.handle}`}>{product.name}</a>
            <span>
              {formatMoney(product.price, {
                symbol: config?.currencySymbol ?? "دج",
                locale: config?.locale ?? "ar-DZ",
              })}
            </span>
          </li>
        ))}
      </ul>
    )}
  </body>
</html>
```

يعمل `config.get()` و`products.list()` بالتوازي لأن كليّهما لا يحتاج إلى نتيجة
الآخر. كل استدعاء ينفّذ طلبه الخاص؛ ولا ينتظر العميل أبدًا استدعاءً مماثلًا
معلّقًا. شارك النتيجة داخل العرض بدلًا من السؤال مرتين.

## 4. اعرض صفحة منتج

استخدم **handle** العام للمنتج، لا معرّفًا داخليًا. المنتج المفقود 404 حقيقي، لا
صفحة فارغة برمز 200.

```astro
---
// src/pages/products/[handle].astro
import { formatMoney } from "@wocart/storefront";
import { getStore } from "../../theme/store";

const store = getStore();
const [config, product] = await Promise.all([
  store.config.get(),
  store.products.get(Astro.params.handle!),
]);

if (!product) return Astro.rewrite("/404");
---
<article>
  <h1>{product.name}</h1>
  <p>
    {formatMoney(product.price, {
      symbol: product.currency,
      locale: config?.locale ?? "ar-DZ",
    })}
  </p>
  {product.description &&
    (product.descriptionFormat === "html" ? (
      <div set:html={product.description} />
    ) : (
      <p>{product.description}</p>
    ))}
</article>
```

ملف المسار ملكك. أما المسار فملك المنصة: يعيش المنتج في `/products/:handle`.
ابنِ الروابط بـ `storefrontPath` بدلًا من كتابة النص يدويًا.

```ts
import { storefrontPath } from "@wocart/storefront";

storefrontPath("product", { handle: product.handle }); // /products/linen-shirt
storefrontPath("checkout"); // /checkout
```

المعامل المفقود يرفع خطأ. هذا مقصود: الرابط إلى لا مكان يجب أن يفشل حيث يُبنى،
لا أن يُعرض كعنوان URL مكسور.

## 5. أبقِ المتصفح بعيدًا

لا يستورد المتصفح `@wocart/storefront/server` أبدًا. يستورد الجذر للأنواع
والمساعدات، ويستدعي مساراتك من نفس المصدر للبيانات التي تحتاج المفتاح.

```ts
// Browser code: safe.
import { createBasketStore, formatMoney } from "@wocart/storefront";

// Server code only: never in a browser script.
import { createStoreClient } from "@wocart/storefront/server";
```

تحتاج مسارات البروكسي وإجراء إنشاء الطلب والبرمجيات الوسيطة إلى إعداد قصير:

- [إجراءات ومسارات Astro](/ar/sdk/storefront/astro) يربط حدود المتصفح.
- [السلة وعروض الأسعار](/ar/sdk/storefront/basket) يضيف السلة.
- [إتمام الطلب وOTP](/ar/sdk/storefront/checkout) ينشئ طلبًا.
- [إعداد المتجر واللغات](/ar/sdk/storefront/config) يضيف التوجيه حسب اللغة.

<Callout type="info" title="هل تبني قالبًا قابلًا للتحرير؟">
أضف [`@wocart/theme`](/ar/sdk/theme) بجانب هذا SDK. تبقى بيانات واجهة المتجر آتية
من مساحات الأسماء هذه؛ ويوفّر SDK القوالب مستندات الصفحات المحرّرة ومحرك العرض.
`pageData.get("home")` يخبرك بما حفظه المتجر.
</Callout>
