# SDK واجهة المتجر

`@wocart/storefront` هو صلة واجهة متجرك بـ CodFlow. يقرأ كتالوج المتجر وبيانات
التوصيل والمحتوى المحفوظ، ويرسل السلال والمراجعات ورموز OTP والطلبات إلى الخادم
الذي يملك القواعد.

صفحات Astro الخاصة بك تقرر شكل المتجر. وSDK يقرر ما يمكن قراءته وإرساله بأمان.
تبقى الأسعار والمخزون ورسوم التوصيل والخصومات وقبول الطلب على الخادم.

<Callout type="info" title="الواجهة الثابتة خيار حقيقي">
لا تحتاج إلى أدوات تحرير CodFlow لبناء واجهة متجر. موقع Astro بهذا SDK ومكوّناتك
الخاصة مكتمل. ويضيف [SDK القوالب](/ar/sdk/theme) الاختياري تحرير التاجر ومستندات
الصفحات المحفوظة والمعاينة.
</Callout>

## ما يقدّمه SDK

- **قراءات مُعرّفة الأنواع.** تصل المنتجات والفئات والصفحات والقوائم والأسعار
  والإعدادات بالشكل الذي تحقق منه الخادم.
- **أعطال متوقعة.** تنتهي القراءات إلى `null` أو `[]` أو `{}` وتُبلّغ عن السبب
  عبر `onError`. أما عمليات الكتابة فتعيد نتيجة يمكنك التفريع عليها.
- **نقطة دخول آمنة للمتصفح.** لا تحتوي نقطة الدخول الجذرية على مصنع عميل ولا
  مفتاح API. يستطيع كود المتصفح استيرادها بحرية، بينما يبقى المفتاح على الخادم.
- **مهايئات Astro.** المسارات من نفس المصدر ومحرك نموذج الطلب والوسيط الذي يعرض
  نموذجًا مرفوضًا جاهزة للربط.
- **مساعدات المتصفح.** مخزن السلة وآلة حالات OTP وعناوين الصور وتنسيق المال
  والتعبئة المسبقة لـ WhatsApp جزء من الحزمة.

## ما تقوم بتثبيته

```bash
npm install @wocart/storefront zod
```

`zod` 4.x اعتماد نظير. الحزمة ESM فقط وتحتاج أدواتها إلى Node 22.12 أو أحدث.
تم التحقق من Astro 7، لكن النواة لا تستورد Astro؛ المهايئات تحت
`@wocart/storefront/astro` بنيوية.

## ثلاثة استيرادات وحدود واحدة

| الاستيراد | يعمل في | ما يحتويه |
| --- | --- | --- |
| `@wocart/storefront` | المتصفح والخادم | الأنواع ومساعدات المال والصور وبيانات المرجع والسلة وآلة OTP ومسارات الصفحات وحمولات Meta |
| `@wocart/storefront/server` | الخادم فقط | `createStoreClient` وفحوص المعاينة وإعادة التحقق |
| `@wocart/storefront/astro` | الخادم فقط | `createStorefrontRoutes` و`createProxyEndpoint` و`placeOrderInput` و`executePlaceOrder` و`runFormAction` |
| `@wocart/storefront/review-media` | المتصفح فقط | تصغير الصور وتسجيل الصوت لنموذج المراجعة |

<Callout type="caution" title="لمفتاح المتجر مكان واحد">
يحتوي `@wocart/storefront/server` على مفتاح API الخاص بالمتجر. لا تستورده أبدًا من
سكربت متصفح أو جزيرة أو متغير عام. يستدعي كود المتصفح مساراتك من نفس المصدر،
وتستدعي تلك المسارات SDK على الخادم.
</Callout>

## ما يغطيه العميل

| مساحة الأسماء | استخدمها في |
| --- | --- |
| `config` | هوية المتجر واللغات وسياسة إتمام الطلب ومفاتيح الميزات |
| `products` | قوائم المنتجات وصفحة المنتج والمراجعات |
| `collections` | قوائم منتجات منسّقة من التاجر وصفحات المجموعات |
| `categories` | تنقل الكتالوج |
| `pages` | الصفحات القانونية وصفحات CMS وصفحات الهبوط |
| `menus` | قوائم تنقل المتجر |
| `pageData` | مستند الصفحة المحفوظ لقالب قابل للتحرير |
| `shipping` | أسعار التوصيل الافتراضية لكل ولاية |
| `geo` | الولايات والبلديات |
| `cart` | إعادة تسعير على الخادم والكوبونات وعروض أسعار التوصيل |
| `orders` | إنشاء الطلب وOTP والسلة المتروكة والتتبع |

## ما لا يفعله

لا يعرض SDK الصفحات، ولا يخزّن سلة المتصفح على الخادم، ولا يرفع الصور إلى R2،
ولا يكتب مستندات الصفحات، ولا يقرر تخطيط القالب أو نصوصه أو حركته. كما لا يجعل
سعرًا قديمًا في المتصفح موثوقًا.

تعيش قواعد التجارة على الخادم. إذا احتاجت ميزة قاعدة جديدة، فغيّر عقد الخادم
أولًا، ثم استخدمها هنا.
