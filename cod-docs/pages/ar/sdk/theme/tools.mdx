# الأدوات وخريطة الطريق

<Callout type="caution" title="CLI وعدة البدء غير متاحين بعد">
إن CLI وعدة البدء في هذه الصفحة **مخططان**. وهما مدرجان هنا لتختار مسارًا
الآن، لا لأن عليك انتظارهما. أما مهارة الذكاء الاصطناعي فهي موجودة فعلًا في

## ما يمكنك استخدامه اليوم

لا تحتاج إلى أداة خاصة لبناء قالب CodFlow. المسار الحالي هو:

| الحاجة | استخدم اليوم |
| --- | --- |
| مثال عامل لنسخه | [التنفيذ المرجعي](/ar/sdk/theme/reference-implementation) Theme-00 |
| تسلسل الإعداد الكامل | [ابنِ قالبًا كاملًا](/ar/sdk/theme/tutorial) |
| تغييرات آمنة على النصوص والصور والتخطيط | [تخصيص قالب](/ar/sdk/theme/customize) |
| قواعد لمساعد ذكاء اصطناعي | [استخدام الذكاء الاصطناعي لبناء قالب](/ar/sdk/theme/agents) ومهارة `wocart-theme` في المستودع |
| فحص إصدار قابل للتكرار | [اختبار قالب](/ar/sdk/theme/testing) |
| قائمة قبل النشر | [الإنتاج والترقية](/ar/sdk/theme/production) |

إذا كنت تحتاج فقط إلى تصميم مخصص لمتجر واحد ولن يحرّره أحد من لوحة تحكم،
فيمكنك تجاوز هذه الأدوات كليًا. ابنِ واجهة متجر Astro بـ
[`@wocart/storefront`](/ar/sdk/storefront).

## مهارات الذكاء الاصطناعي

يشحن المستودع مهارة وكيل في `.agents/skills/wocart-theme/`. وهي إجراءات لا
مكتبة: يقرأها الوكيل قبل أن يلمس قالبًا.

| المرجع | ما يجعل الوكيل يفعله |
| --- | --- |
| `SKILL.md` | المسارات الأربعة، والقواعد التي لا تُلين، والأوامر التي يجب أن ينتهي بها كل تغيير |
| `references/sdk-discovery.md` | فحص النسخة المثبّتة، وقراءة التعريفات والاختبارات، والتحقق من كل API قبل استخدامه |
| `references/theme-architecture.md` | الفصل بين SDK القالب وSDK الواجهة، وقراءة Theme-00 دون نسخه، وبناء قالب جديد على عقود مدعومة |
| `references/theme-quality.md` | إثبات الأنواع والمخطط والصفحات والعربية/RTL والتجاوب والحالات والدمج والبناء — لا ادّعاء بلا فحص ناجح |
| `references/docs-maintenance.md` | تغيير العقد يستدعي الصفحات الإنجليزية والفرنسية والعربية، والأمثلة، والمهارات |

وجّه مساعدك إلى المهارة وإلى البيان، فيتوقف عن تخمين أسماء الحقول. والقواعد
التي تفرضها هي قواعد [استخدام الذكاء الاصطناعي لبناء قالب](/ar/sdk/theme/agents).

## قريبًا

### CLI القالب

رفيق سطر أوامر للأجزاء المملة والقابلة للتكرار:

- إنشاء قالب من عدة البدء؛
- التحقق من كتالوج المكوّنات والبيان والمستندات المضمّنة؛
- فحص أن قالبًا جاهز للمشاركة أو النشر؛
- تشغيل الفحوص نفسها محليًا وفي CI.

سيستخدم CLI العقد الموثّق هنا. ولن يخترع طريقة ثانية لتعريف القوالب.

### عدة البدء

قالب صغير وكامل تبدأ منه بدلًا من مجلد فارغ. من المخطط أن يتضمن:

- سطح صفحة واحدًا ومنطقة مشتركة واحدة؛
- قسمًا واحدًا بحقول قابلة للتحرير؛
- فتحة واحدة بكتلة فرعية؛
- نقطة نهاية بيان؛
- اختبارات العقد الموصوفة في [اختبار قالب](/ar/sdk/theme/testing).

عدة البدء مقصودة للقراءة والتشغيل ثم التغيير. إنها ليست تصميمًا مكتملًا لواجهة متجر.

## أي مسار تختار؟

| هدفك | ابدأ الآن | انتظر الأدوات؟ |
| --- | --- | --- |
| واجهة متجر مخصّصة ثابتة لمتجر واحد | Astro + `@wocart/storefront` | لا |
| قالب يستطيع التاجر تحريره | [ابنِ قالبًا كاملًا](/ar/sdk/theme/tutorial) | لا؛ ستوفر عدة البدء وقت الإعداد لاحقًا |
| قالب للمشاركة أو البيع | ابنِ، ثم [البيان](/ar/sdk/theme/manifest) و[الاختبار](/ar/sdk/theme/testing) | ليس مطلوبًا، لكن CLI سيسهّل الإصدارات |
| البناء مع مساعد ذكاء اصطناعي | [استخدام الذكاء الاصطناعي لبناء قالب](/ar/sdk/theme/agents) ومهارة `wocart-theme` | لا |

## كيف ستتغير هذه الصفحة

عندما يصدر CLI أو عدة البدء، سيصبح قسمه هنا تعليمات تثبيت واستخدام. حتى ذلك
الحين، تعامل معهما كتوجيه، لا كوعد API — ومع المهارة كملف يمكنك قراءته اليوم.
