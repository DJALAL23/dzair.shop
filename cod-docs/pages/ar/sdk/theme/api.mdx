# واجهة API العامة

هذه الصفحة خريطة منظّمة لـ `@wocart/theme` 2.1.0: ما تصدّره كل نقطة دخول، وفيمَ
تُستخدم، وما ليس جزءًا من العقد. [المرجع المولَّد](/sdk/theme/reference/README)
يحوي كل التوقيعات؛ وهذه الصفحة تقول أيّها تستخدم.

```sh
npm install @wocart/theme @wocart/storefront
```

| الاستيراد | يعمل في | يحوي |
| --- | --- | --- |
| `@wocart/theme` | المتصفح والخادم | التعريفات، التحقق، المستندات، العمليات، الإعدادات، النصوص، الأنماط، البيان، بروتوكول المعاينة — بلا Astro وبلا إدخال/إخراج |
| `@wocart/theme/astro` | الخادم والبناء | ذاكرة القراءة، ونقطتا نهاية البيان وورقة الأنماط، وأدوات الفتحات والمعاينة |
| `@wocart/theme/astro/InstanceView.astro` | الخادم والبناء | المُصيّر المرجعي |
| `@wocart/theme/astro/Blocks.astro`, `Block.astro` | الخادم والبناء | بلوكات فتحة ما، وبلوك ثابت واحد |
| `@wocart/theme/astro/ThemeStyles.astro` | الخادم والبناء | رابط ورقة الأنماط وCSS أنظمة الألوان |
| `@wocart/theme/image-service` | البناء | `mediaImageService` لخيار `image.service` في Astro |
| `@wocart/theme/preview` | المتصفح | `startPreviewBridge` لصفحة معاينة القالب |

نقطة الدخول الجذرية لا تستورد أي وحدة Astro ولا تنفّذ إدخال/إخراج، فتعمل في
اختبار وحدة أو سكربت. والتحقق مكانه الخادم أو البناء: مخطط داخل صفحة متسوّق
يرسل Zod إلى كل زائر.

## التعريفات والتحقق

| التصدير | ما يفعله |
| --- | --- |
| `defineComponent(definition)` | مساعد هوية: يحفظ حرفية الحقول، ويكتب أنواع `load` من الحقول، ويكتب أنواع خصائص المكوّن |
| `defineTheme(definition)` | مساعد هوية للكتالوج |
| `defineCapabilities(capabilities)` | ثابت `capabilities` مشترك، مكتوب النوع لكي يواصل `defineComponent` استنتاج حقوله |
| `componentsOf(theme)` | مكوّنات القالب كتعريفات، بترتيب الكتالوج — ما يمرّ عليه الاختبار أو الأداة |
| `validateThemeDefinition(theme, options?)` | فحص التجميع: تطابق المفتاح والنوع، الحقول، الفتحات، البلوكات، القوالب الجاهزة، المستندات، مفاتيح المحتوى، وضمان نموذج الطلب. `[]` هي النجاح الوحيد |
| `themeManifest(theme)` | البيان القابل للتسلسل؛ يُسقط `component` و`load` |
| `validateThemeManifest(input)` | حدّ لـ JSON: قابلية التسلسل، البنية، ثم القواعد العلائقية نفسها. `{ manifest, issues }` |
| `manifestCatalog(manifest)` | `ThemeDefinition` بـ `component: null` — للتحرير والتحقق، لا للعرض أبدًا |
| `diffThemeManifests(previous, next)` | `{ breaking, additive }` بين إصدارين |
| `THEME_SDK_VERSION` | نسخة الحزمة المسجّلة في البيان (`"2.3.0"`) |
| `THEME_MANIFEST_CONTRACT_VERSION` | نسخة صيغة البيان (`1`) |
| `THEME_MANIFEST_PATH` | `/wocart-theme.json` |

`validateThemeDefinition` يأخذ خيارًا واحدًا: `contentKeys`، مجموعة المفاتيح التي
يجب أن يوجد فيها كل `contentKey`. تمرير مصفوفة فارغة ذو معنى: يفعّل الفحص
ويبلّغ عن كل مفتاح معلن.

## المستندات والنسخ المعروضة

| التصدير | ما يفعله |
| --- | --- |
| `parsePageData(input)` | يقرأ مستندًا محفوظًا بتسامح: `{ page, issues }`؛ و`page` تكون null فقط عند تلف الغلاف |
| `validatePageData(theme, input, scope?)` | القراءة نفسها مقابل كتالوج، مع `unknown-type` وترشيح الفتحات |
| `resolveInstance(definition, instance, scope?)` | نسخة واحدة → `{ props, children, slots, fixed, issues }`؛ قلب المُصيّر |
| `createInstance(definition, id, props?)` | ينشئ نسخة فعلية؛ يرفع خطأً عند مفتاح غير معروف أو نوع خاطئ أو حقل مطلوب بلا قيمة |
| `checkFieldValue(field, value)` | فحص كتابة لقيمة واحدة: `{ ok: true, value }` أو `{ ok: false, message }` |
| `resolveSurfaceDocument(theme, surface, saved, scope?)` | أي مستند يُعرض، مكتملًا: `{ page, source, reason, issues }` |
| `completePage(theme, page)` | يضيف كل بلوك ثابت ومطلوب؛ `{ page, issues }` |
| `isFieldVisible(field, values)` | يقيّم `visibleIf` لحقل مقابل قيم الحقول المجاورة — للمحرّرات فقط |
| `CONDITION_DEPTH` | أقصى عمق لشرط (`4`) |

## عمليات المستندات

الكاتبون — محرّر أو سكربت أو وكيل — يغيّرون المستندات عبر هذه الدوال. كل واحدة
تعيد `{ ok: true, page }` أو `{ ok: false, issue }`، ولا واحدة تعدّل مدخلها.

| التصدير | ما يفعله |
| --- | --- |
| `insertInstance(theme, page, instance, placement?)` | يضع نسخة جديدة عند `{ parent?, slot?, index? }` (بلا أب: قسم في المستوى الأعلى) |
| `moveInstance(theme, page, id, placement?)` | يعيد مكان نسخة موجودة |
| `duplicateInstance(theme, page, id, newId)` | ينسخ نسخة وشجرتها بمعرّفات جديدة من `newId` |
| `setInstanceProps(theme, page, id, changes)` | يدمج خصائص، كل واحدة مفحوصة مقابل حقلها |
| `setInstanceHidden(theme, page, id, hidden)` | يخفي أو يظهر، ويرفض للبلوكات الثابتة والمطلوبة |
| `removeInstance(theme, page, id)` | يحذف نسخة وشجرتها، ويرفض إذا كان التركيب يفرضها |
| `findInstance(page, id)` | `{ instance, parent, slot, index, depth, fixed? }` أو `null` |
| `newInstanceId()` | `cmp_` ثم 16 رقمًا ست عشريًا |
| `checkPageData(theme, input)` | كل مشكلة يجب إصلاحها قبل الحفظ: `DocumentIssue[]` |

`removeInstance(page, id)` و`setInstanceHidden(page, id, hidden)` ما زالتا تقبلان
الصيغة بلا قالب؛ وهي **مهجورة**، لأن كاتبًا بلا القالب لا يعرف الأنواع المطلوبة
في الفتحة.

## `@wocart/theme/astro`

| التصدير | ما يفعله |
| --- | --- |
| `createReadCache()` | `ReadCache` واحد لكل عرض صفحة: أول استدعاء لمفتاح يشغّل المحمّل، والاستدعاءات التالية تعيد القيمة المحسومة **ورفضها** |
| `themeManifestEndpoint(theme)` | معالج `GET` للبيان المبني مسبقًا؛ يرفع خطأً عند تحميل الوحدة إذا كان البيان غير صالح |
| `themeStylesEndpoint(theme)` | معالج `GET` لفئات الأنماط، بـ `text/css` |
| `hasBlocks(blocks, slot?)` | هل تحتوي فتحة بلوكًا يُعرض — لتجنّب غلاف فارغ |
| `isPreview(blocks)` | هل هذا العرض معاينة محرّر؛ العناصر البديلة مكانها هناك فقط |
| `previewTarget(theme, draft, client)` | ما تعرضه معاينة المحرر: السطح، ونوع صفحته، والمنطقة المحررة، ومعاملات المسار، والمستند — و`null` لسطح لا يركّبه القالب |
| `BlocksHandle`, `RendererIssue` | خاصية `blocks` التي يستقبلها المكوّن، وصيغة مشكلة من المُصيّر |
| `resolveInstance`, `THEME_LIMITS`, `THEME_STYLES_PATH`, `colorSchemeCss`, `previewStartMarker`, `previewEndMarker` | إعادة تصدير من الوحدة الجذرية، ليعمل الاستيراد المجاور في المصادر وفي `dist` |

المكوّنات الأربعة: `InstanceView.astro` (المُصيّر)، و`Blocks.astro`
(`<Blocks of={blocks} slot="info" />`)، و`Block.astro`
(`<Block of={blocks} name="gallery" />`)، و`ThemeStyles.astro`
(`<ThemeStyles schemes={settings.colorSchemes} />`).

## `@wocart/theme/image-service` و`/preview`

| التصدير | ما يفعله |
| --- | --- |
| `mediaImageService(mediaDomain)` | خدمة صور لـ Astro تغيّر مقاس صور نطاق الوسائط على نطاق الوسائط نفسه؛ `mediaDomain` دالة تُقرأ عند كل صورة، فقيمة البناء تُقرأ بعد تحميل البيئة |
| `mediaImageParams(options)` | معاملات الاستعلام التي تبنيها الخدمة لتحويل Astro |
| `startPreviewBridge({ editorOrigin, token, endpoint?, window? })` | الجانب المتصفحي لصفحة المعاينة: تعديل البنية، رسائل التأشير والاختيار، وطلبات إعادة العرض. يعيد `{ stop() }` |
| `PREVIEW_SECTION_LOAD_EVENT` | `"wocart:section-load"` — يُطلق لكل قسم استبدله الجسر |

## `@wocart/theme/lifecycle` و`/messages`

مدخلا المتصفح: صغيران جدًا، بلا Zod، وآمنان على صفحة كل متسوق.

| التصدير | ما يفعله |
| --- | --- |
| `bindEach(selector, bind, options?)` | يربط كل عنصر مطابق مرة واحدة — عند التحميل، وبعد أن يستبدل موجّه Astro الصفحة، وبعد أن تُدخل معاينة المحرر قسمًا. ويمكن للربط أن يُعيد دالة تفكيك |
| `onEachPage(boot, options?)` | يشغّل سلوك الصفحة مرة لكل صفحة، وتفكيكه قبل استبدال الصفحة |
| `PREVIEW_SECTION_LOAD_EVENT` | ‏`"wocart:section-load"`، دون الجسر: لا يسمّي القالب أحداث الاستبدال بنفسه أبدًا |
| `formatMessage(pack, key, values?, { locale })`، `messageForms(pack, key)`، `pluralMessageKeys(pack)` | رسالة من النصوص، وتُختار صيغة جمعها حسب `count` ‏(`/messages`) |

<Callout type="caution" title="ما ليس عامًّا">
المسارات العميقة `dist/…` و`src/…` تفاصيل تنفيذ. و`ComponentDefinition.component`
و`.load` كود لا يُسلسل أبدًا؛ و`manifestCatalog` يعيد تعريفات بلا مكوّن، فهو
للتحرير لا للعرض. و`key` القالب جزء من العقد: تغييره يُيتّم تعديلات التاجر.
</Callout>

## النسخة

يجب أن تساوي `THEME_SDK_VERSION` نسخة `package.json` المثبّتة — وفحص الحزمة
يرفض إصدارًا تختلف فيه. والبيان يسجّلها، فيعرف المحرّر ما يقرأه مُصيّر القالب.
راجع [الإنتاج والترقية](/sdk/theme/production#versions-and-upgrades) لنطاقات
الـ peers وقائمة الترقية.
