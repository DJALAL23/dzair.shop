# المعاينة

تتيح المعاينة للتاجر التحرير في CodFlow Studio ورؤية النتيجة على واجهة المتجر
الحقيقية: المكوّنات نفسها وبيانات المتجر نفسها وCSS نفسه الذي يستقبله المتسوق.
يغيّر التاجر قيمة؛ فتُعاد الصفحة في الإطار.

يشترك القالب بـ `preview: true` ويقدم مسارًا على **`/wocart-preview`**. ويخبر
البيان CodFlow Studio بأن المسار موجود.

إذا كان قالبك تصميم Astro ثابتًا ولا أحد يحرّره من لوحة تحكم، فلا تحتاج إلى هذه
الصفحة.

## الأجزاء الثلاثة

### 1. الطلب

يؤطّر CodFlow Studio:

```text
GET /wocart-preview?token=…&surface=home&locale=fr
```

تتحقق `readPreviewRequest` من `@wocart/storefront/server` من الرمز الموقّع
القادم من CodFlow Studio وتعيد المسودة: أي سطح وأي لغة يُعرضان، ثم — بعد أن
يرسل Studio واحدًا — المستند والإعدادات وتعديلات النص. وكل ما تغفله المسودة
يُعرض كما لو كان محفوظًا.

يجيب المسار بـ `previewResponseHeaders`، فلا يستطيع إلا Studio تأطيره ولا
تُخزَّن أي استجابة. ولا يجوز لأي قاعدة مسار تخزينه مؤقتًا.

```ts
// src/middleware.ts
import { readPreviewRequest } from "@wocart/storefront/server";

const preview = await readPreviewRequest(context.request, {
  publicKey: WOCART_PREVIEW_KEY,
  theme: THEME_KEY,
});
if (!preview.ok) {
  return new Response(null, {
    status: preview.status,
    headers: { "Cache-Control": "no-store" },
  });
}
context.locals.preview = preview;
```

```astro
---
// src/pages/wocart-preview.astro
import { previewResponseHeaders } from "@wocart/storefront/server";

export const prerender = false;
const { claims, token } = Astro.locals.preview;
for (const [name, value] of Object.entries(previewResponseHeaders(claims))) {
  Astro.response.headers.set(name, value);
}
---
```

يجب أن يطابق القالب الموجود في الرمز القالب الذي يقدم المسار؛ وتُرفض معاينة
لقالب آخر. وإذا لم يُضبط مفتاح معاينة، فالمعاينة معطلة ويجيب كل طلب من هذا
النوع بـ `404`.

### 2. العلامات

يحيط `<InstanceView preview …>` عُقد كل نسخة بتعليقي HTML:

```html
<!--wocart:start id=hero-1 type=hero-->
<section>…</section>
<!--wocart:end id=hero-1-->
```

تعليقات، لا عناصر تغليف، حتى تتنسّق الشبكة أو محدّد `> *` تمامًا كما تفعل لدى
المتسوق. وتحتفظ النسخة المخفية بعلاماتها وليس بينها شيء. ولا تحمل صفحة المتسوق
أيًا منها.

المساعدات هي `previewStartMarker` و`previewEndMarker` و`parsePreviewMarker`.

### 3. الجسر

يعمل `startPreviewBridge({ editorOrigin, token })` من `@wocart/theme/preview` على
صفحة المعاينة. وهو:

- يبلّغ CodFlow Studio بكل نسخة معلّمة،
- يحوّل النقرات إلى تحديدات في وضع التحرير،
- يعيد عرض المسودات التي يرسلها Studio،
- يستبدل فقط الأقسام التي تغيّر ترميزها.

ولا يرسم شيئًا. فخطوط التحديد وأشرطة الأدوات واللوحات ملك لـ Studio.

```astro
---
// src/pages/wocart-preview.astro
export const prerender = false;
const { claims, token } = Astro.locals.preview;
---
<Layout>
  {sections.map((instance) => (
    <InstanceView preview {instance} {theme} {context} {storefront} {reads} />
  ))}
  <wocart-preview-bridge data-editor={claims.editor} data-token={token} hidden />
</Layout>
<script>
  import { startPreviewBridge } from "@wocart/theme/preview";
  const host = document.querySelector<HTMLElement>("wocart-preview-bridge")!;
  startPreviewBridge({ editorOrigin: host.dataset.editor!, token: host.dataset.token! });
</script>
```

يرسل CodFlow Studio مسودة جديدة بإرسالها مرة أخرى إلى المسار بصيغة JSON — وليس
عبر نموذج بين المواقع أبدًا، ليبقى `checkOrigin` في Astro مفعّلًا.

## البروتوكول

كل رسالة `{ source, version, type, … }`. ترسل الصفحة `source: "wocart-preview"`؛
ويرسل Studio `source: "wocart-editor"`. ويرسل الطرفان إلى أصل الآخر الدقيق،
ويتحققان من `event.origin` و`event.source` قبل قراءة أي رسالة.

`PREVIEW_PROTOCOL_VERSION` هي `1`.

| يرسل المحرر | تجيب الصفحة |
| --- | --- |
| — | `ready` مع كل نسخة: `{ id, type, parent, hidden, rect }` |
| `render` `{ draft, revision? }` | `rendered` `{ revision, instances }`، أو `error` `{ revision, reason }` |
| `patch` `{ patches }` | التغيير فورًا، ثم `layout` |
| `mode` `"edit"` أو `"interactive"` | في `edit` تحدد النقرات النسخة الأعمق؛ وفي `interactive` تعمل الروابط والنماذج |
| `scroll-to` `{ id }` | تُمرَّر النسخة إلى مجال الرؤية |
| `token` `{ token }` | يستخدمه العرض التالي |
| — | `hover` `{ id \| null }` أثناء حركة المؤشر؛ و`layout` بعد التمرير أو تغيير الحجم |

يُسقط أي عرض يُجاب عنه بعد عرض أحدث — أو بعد رقعة. والمسودة الأحدث تفوز دائمًا.

## الرقع

الرقعة تلميح يتيح للصفحة إظهار تغيير قبل وصول العرض البطيء. وتطبّق الصفحة ما
تجده وتترك الباقي للعرض، وهو حقيقة الصفحة. ويرسل المحرر العرض أيضًا دائمًا؛
وصفحة ما قبل 1.6.0 تتجاهل الرقع وتعرض كل تغيير بعد لحظة.

| الرقعة | ما تعرضه |
| --- | --- |
| `move` `{ id, index, parent? }` | نسخة عند فهرس بين أشقائها |
| `duplicate` `{ id, ids }` | نسخة بعدها مباشرة؛ و`ids` يربط كل معرّف أصلي بنسخته |
| `remove` `{ id }` | النسخة وكل ما داخلها اختفيا |
| `restore` `{ id, index, parent? }` | ما أخذه remove، عند فهرس |
| `hide` `{ id, hidden }` | النسخة معروضة أو مطفأة |
| `text` `{ id, from, to }` | تغيّر نص داخل نسخة |

## سلوك المتصفح داخل قسم

لا تعمل سكربتات القسم المستبدل مرة أخرى؛ فالمتصفح لا ينفّذ سكربتًا أُدرج عبر
الترميز أبدًا. والقسم الذي له سلوك متصفح يربطه مجددًا على
`PREVIEW_SECTION_LOAD_EVENT` (`wocart:section-load`، يُطلق على `document` مع
`detail.id`):

```ts
document.addEventListener(PREVIEW_SECTION_LOAD_EVENT, (event) => {
  const { id } = (event as CustomEvent<{ id: string }>).detail;
  mountSection(id);
});
```

وعندما يستبدل الجسر الصفحة كاملة، يفعل ما يفعله موجّه Astro بعد التنقل —
`<body>` جديد وسمات العنصر الجذر والعنوان — ويطلق `astro:page-load`، فيُركَّب
السكربت المكتوب للموجّه مجددًا كما يفعل هناك. وتُستبدل أوراق الأنماط المتغيرة
في مكانها؛ أما غير المتغيرة فلا تُعاد تحميلها أبدًا.

## الأمان

| الضابط | الأثر |
| --- | --- |
| رمز موقّع له مدة صلاحية | جلسة محرر حقيقية فقط تستطيع فتح معاينة |
| `previewResponseHeaders` | ذلك المحرر وحده يستطيع تأطيره؛ ولا يُخزَّن |
| POST مع JSON لمسودة جديدة | لا نموذج بين المواقع؛ ويبقى `checkOrigin` مفعّلًا |
| `editorOrigin` الدقيق | لا ينشر الجسر في أي مكان آخر |
| فحوص `event.origin` و`event.source` | لا يُسمع إلا المحرر المؤطِّر |
| فحوص `source` و`version` | تُتجاهل الرسالة القديمة أو الغريبة |
| علامات في المعاينة فقط | صفحة المتسوق لا تحوي أي بيانات وصفية للمعاينة |

لا تُخزَّن المعاينة مؤقتًا أبدًا. فقد تحوي مسودة غير محفوظة أو سعرًا مسودًّا أو
منتجًا مسودًّا لا يجوز للمتسوق رؤيته.
