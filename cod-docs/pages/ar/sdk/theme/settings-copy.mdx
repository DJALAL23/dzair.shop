# الإعدادات والنصوص

**الإعداد** خيار للمتجر كله — خط، أو قائمة الترويسة، أو مخططات الألوان. و**الحقل**
خيار لقسم واحد. وكلاهما يستخدم أنواع الحقول نفسها؛ والإعدادات تعيش في مجموعات
مسماة وتُخزَّن مسطحة بالمفتاح.

## إعلان إعداد

```ts
const theme = defineTheme({
  // …
  settings: [
    {
      key: "appearance",
      label: { en: "Appearance", fr: "Apparence" },
      fields: [
        {
          key: "headingFont",
          kind: "select",
          label: "Heading font",
          options: ["sans", "serif"],
          optionLabels: { sans: "Sans", serif: "Serif" },
          default: "sans",
        },
        {
          key: "colorSchemes",
          kind: "colorSchemes",
          label: "Color schemes",
          default: [/* … */],
        },
      ],
    },
  ],
});
```

| القاعدة | الأثر |
| --- | --- |
| `key` المجموعة | بحروف صغيرة بنمط kebab-case، فريد في القالب |
| `key` الحقل | فريد في **كل** المجموعات؛ وهو المفتاح المخزّن |
| `colorSchemes` | واحد على الأكثر في القالب؛ راجع [التنسيق واللون](/ar/sdk/theme/style) |
| الإعدادات | تُقرأ مسطحة: `values.headingFont`، لا `values.appearance.headingFont` |

## قراءة إعدادات متجر

```ts
import { resolveThemeSettings } from "@wocart/theme";

const { values, issues } = resolveThemeSettings(theme, store.settings, {
  content: store.content,
  locales: [store.locale, ...store.fallbackLocales],
});
```

الأولوية هي:

1. قيمة التاجر،
2. القيمة الافتراضية للقالب — أو حزمة محتواه، لإعداد نصي،
3. غائبة.

لا ترمي القراءة أبدًا. فالقيمة التي لم يعد الإعلان يقبلها تُبلَّغ
(`invalid-setting` أو `missing-required-setting`) وتُطبَّق القيمة الافتراضية.
والمفتاح الذي لم يعد القالب يعلنه يُبلَّغ (`unknown-setting`) ويُتجاهل. والكائن
المخزّن الذي ليس كائنًا يُبلَّغ (`invalid-settings`) وتُطبَّق كل القيم
الافتراضية.

`InferSettings<typeof theme>` يحدد نوع الناتج: فالإعداد ذو القيمة الافتراضية
حاضر دائمًا؛ وأي إعداد آخر قد يكون غائبًا.

تتحقق الكتابة قبل الحفظ:

```ts
import { checkThemeSettings } from "@wocart/theme";

const issues = checkThemeSettings(theme, candidate);
if (issues.length > 0) console.error(issues);
```

وتتحقق الكتابة أيضًا من أن كل إعداد `colorScheme` يسمّي مخططًا يملكه المتجر
فعلًا.

## النص

يمكن لحقل نصي أن يأخذ قيمته الأولية من **حزمة محتوى** القالب:

```ts
{ key: "heroTitle", kind: "text", label: "Title", contentKey: "heroTitle" }
```

تُحل القيمة بهذا الترتيب:

1. قيمة النسخة المحفوظة،
2. `context.content[contentKey]`،
3. `default` الخاص بالحقل،
4. غائبة — فتُطبَّق القيمة الافتراضية لخاصية المكوّن.

`contentKey` و`default` متعارضان. ولا يمكن لعنصر قائمة استخدام `contentKey`: فكل
عنصر سيقرأ السلسلة نفسها. ولا يمكن لحقل نص منسّق استخدامه أيضًا، لأن حزمة
المحتوى تحمل نصًا عاديًا.

## حزم المحتوى

القالب يملك نصوصه وتصنيفه. ولا ينمذج SDK نظام محتوى؛ بل يقرأ الحزمة المحلولة
التي يمررها الطلب إليه:

```ts
content: {
  en: { heroTitle: "Welcome", viewAll: "View all" },
  fr: { heroTitle: "Bienvenue", viewAll: "Tout voir" },
  ar: { heroTitle: "مرحبا", viewAll: "عرض الكل" },
}
```

- الحزمة `Record<string, string>` **معتمة ومسطحة**. وأي بنية مفاتيح تختارها هي
  اختيار القالب.
- `ThemeRenderContext.content` هي الحزمة **للغة الحالية**، وقد دُمجت فيها
  تجاوزات المتجر مسبقًا.
- إعلان الحزم يجعل الفحص أقوى: فـ `validateThemeDefinition(theme)` يبلّغ عن
  `contentKey` غائب من حزمة (`unknown-content-key`)، ويجب أن يكون لكل لغة معلنة
  حزمة.
- إذا لم يعلن القالب حزمًا، فافحص مقابل مجموعة مفاتيحه الخاصة بـ
  `validateThemeDefinition(theme, { contentKeys })`.
- ويمكن للقالب أيضًا قراءة الحزمة كاملة وتركيب قيمه المحلولة فوقها. ولا يشحن
  SDK عمدًا أي مساعد لذلك: فذلك سيجعل نموذج نصوص قالب واحد واجهة برمجة للمنصة.

تُفهرَس تعديلات النص بمفتاح **القالب**. ولا تستقبلها واجهة المتجر إلا عندما
يمرّر عميل SDK الخاص بها القالب. وإعادة تسمية مفتاح القالب تُيتّم كل تعديل تاجر
محفوظ تحت المفتاح القديم.

## تسميات على مستوى المتجر

الحزمة هي أيضًا مكان التسميات على مستوى المتجر — «أضف إلى السلة» و«نفد
المخزون» و«عرض الكل». ويمكن للتاجر تجاوزها في CodFlow Studio. وفي مكوّن، اقرأ
التسمية عبر حقل `contentKey`، أو اقرأ الحزمة:

```ts
const labels = Astro.locals.store.content;
const addToCart = formatMessage(labels, "addToCart", {}, { locale });
```

احتفظ بمفتاح تسمية واحد لمعنى واحد. فإذا استخدم مكوّنان المفتاح نفسه بنص مختلف،
غيّر التجاوز كليهما.

## الرسائل والجموع والعناصر النائبة

`formatMessage` هي قاعدة الرسائل الوحيدة في SDK. وهي تتبع نموذج ملفات اللغة على
بيانات CLDR:

```ts
formatMessage(pack, "cartItems", { count: 3 }, { locale: "ar" });
```

| القاعدة | المثال |
| --- | --- |
| العناصر النائبة `{name}` | `"مرحبا {name}"` ← تُملأ القيمة، وتُنسَّق الأرقام للغة |
| عنصر نائب مجهول | يبقى ظاهرًا (`{name}`)، ولا يختفي أبدًا |
| الجموع | مفاتيح مسطحة لكل صيغة CLDR: `cartItems_one` و`cartItems_few` و`cartItems_other` |
| `_zero` | يُستخدم لعدد 0 في أي لغة، عند وجوده |
| مفتاح مفقود | يعرض المفتاح نفسه، فيظهر النقص |

لا تبنِ رسالة قط بـ `.replace("{n}")`. فقد تحتاج لغة إلى صيغة لا تحتاجها غيرها؛
والعربية لها ست. و`pluralFormIssues(pack, locale)` تسرد الصيغ التي تنقص حزمة أو
تحملها دون استخدام. شغّلها على كل حزمة في اختبار. وتجمع
`messageForms(pack, key)` مفاتيح رسالة لسكربت متصفح.

## اللغة والاتجاه

يمنح `ThemeRenderContext` القسم ما يحتاجه:

| القيمة | المعنى |
| --- | --- |
| `locale` | اللغة التي تُعرض، الأولى في سلسلة التراجع |
| `fallbackLocales` | سلسلة تراجع المتجر بعدها |
| `isRTL` | هل تُقرأ اللغة من اليمين إلى اليسار |
| `content` | الحزمة المحلولة لـ `locale` |

تجرّب القيمة المترجمة `locale`، ثم كل مدخل في `fallbackLocales`، ثم حزمة
المحتوى، ثم القيمة الافتراضية. والترجمة المفقودة ليست خطأ.

`localize(value, [locale, ...fallbackLocales])` من `@wocart/theme` تختار أول لغة
توجد فيها القيمة، أو `undefined` عندما لا توجد في أي لغة. ويطبّق SDK السلسلة
نفسها على قيم الحقول.

لغات المنصة المدعومة واتجاهاتها موجودة في `cod-shared/i18n/locales.ts`؛ ولا
ينسخ قالب تلك القائمة أبدًا. اعرض `dir={context.isRTL ? "rtl" : "ltr"}` على
المستند، واستخدم خصائص CSS المنطقية ليتبع التخطيط.

<Callout type="caution" title="مفتاح القالب هو الهوية">
تُفهرَس تجاوزات نصوص التاجر بـ `defineTheme({ key })`. وتغيير المفتاح يعيد تسمية
القالب للمنصة ويترك التجاوزات القديمة خلفه. تعامل معه كتغيير كاسر.
</Callout>
