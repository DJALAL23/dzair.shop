# تخصيص قالب

استخدم هذه الصفحة عندما يملك القالب بنية قابلة للتحرير بالفعل وتريد تغيير ما
يراه التاجر. لا تحتاج إلى فهم كل نوع في SDK. معظم التغييرات هي قيم في **تعريف**
(الكود الذي يعلن ما يمكن تغييره) أو **مستند صفحة** (JSON المحفوظ لصفحة واحدة).

إذا كان القالب تصميم Astro ثابتًا بلا حقول قابلة للتحرير، فلا يوجد بعد ما
يُخصّص من البيانات المحفوظة. ابدأ بـ [بناء قالب](/ar/sdk/theme/build).

## ما الذي يعيش أين

| تريد تغيير… | أين يوجد | التغيير الآمن |
| --- | --- | --- |
| النصوص ونص alt وتسميات الأزرار | قيمة حقل في مستند الصفحة | غيّر `props` المحفوظة |
| صورة أو شعار | حقل `image` | احفظ **مفتاح** وسائط، لا URL أبدًا |
| منتجات أو مجموعة | `productList` أو `collectionList` أو `collection` أو `product` | غيّر المعرّفات (handles) |
| التباعد والعرض والمحاذاة | حقل `style` | استخدم خطوات القالب وخياراته |
| ألوان الأقسام | حقل `colorScheme` | استخدم أحد معرّفات مجموعات الألوان في المتجر |
| ترتيب الأقسام أو ظهورها | مستند الصفحة | انقل النسخة أو اضبط `hidden: true` |
| الخطوط والزوايا وشكل البطاقات | إعدادات القالب | غيّر قيمة الإعداد |
| خيار جديد قابل للتحرير | تعريف مكوّن | أضف حقلًا، ثم تحقق |
| نوع جديد من الأقسام | الكود | عرّف مكوّنًا وأضفه إلى الكتالوج |

**البيان** هو قائمة الأجزاء القابلة للتحرير في القالب. وإذا لم يكن الحقل في
البيان فهو غير قابل للتحرير؛ غيّر كود القالب بدلًا من ذلك.

## الحلقة الآمنة

1. **اعثر على السطح.** هل هذه الصفحة الرئيسية أم قالب منتج أم فئة أم مجموعة أم
   صفحة هبوط أم صفحة نصية أم الترويسة أم التذييل؟ مفتاح السطح موجود في مستند
   الصفحة وفي البيان.
2. **اعثر على النسخة.** لكل قسم وكتلة `id` و`type`. اقرأ تعريفه أو مدخل البيان
   الخاص بذلك النوع.
3. **غيّر خاصية (prop) معلنة.** استخدم قيمة يقبلها الحقل. لا تخترع مفتاحًا؛ فالمفتاح غير
   المعلن يُتجاهل مع `unknown-prop`.
4. **تحقق.** يفحص `validatePageData(theme, document)` المستند كله مقابل الكتالوج.
   و`checkPageData(theme, document)` هو الفحص الصارم من جانب الكتابة قبل الحفظ.
5. **انظر إليه.** اعرض الصفحة عاديًا، أو افتح مسار المعاينة في CodFlow Studio
   لرؤية مسودة غير محفوظة.

## تغيير النصوص

```json
{
  "id": "hero-1",
  "type": "hero",
  "props": {
    "title": "Livraison partout en Algérie",
    "subtitle": "Payez à la réception."
  }
}
```

يمكن أن تكون القيمة المترجمة خريطة أيضًا:

```json
{
  "title": {
    "ar": "توصيل إلى كل الولايات",
    "fr": "Livraison dans toutes les wilayas"
  }
}
```

السلسلة العادية تعني «الشيء نفسه في كل لغة». لا تستخدم خريطة لغة ما كقيمة
افتراضية لأخرى؛ فالاستخلاص يجرّب اللغة الحالية، ثم سلسلة التراجع في المتجر، ثم حزمة
المحتوى، ثم القيمة الافتراضية للحقل.

## إخفاء قسم

```json
{ "id": "faq-1", "type": "faq", "hidden": true }
```

تبقى الأقسام المخفية في المستند لكنها لا تعرض شيئًا — لا `load` ولا كتل فرعية. والكتلة
**المطلوبة** مختلفة: فالإكمال يعيدها، لأن الصفحة لا يمكن أن تُعرض بدونها.

## نقل قسم

لا تُعِد ترقيم المعرّفات. استخدم عملية مستند؛ فهي تطبّق قواعد الفتحات والموضع
والكتل المطلوبة نفسها التي تطبّقها كل أداة تحرير أخرى:

```ts
import { moveInstance } from "@wocart/theme";

const edit = moveInstance(theme, page, "faq-1", { index: 0 });
if (!edit.ok) console.error(edit.issue.code, edit.issue.message);
```

تتبع `insertInstance` و`removeInstance` و`duplicateInstance` و`setInstanceProps`
و`setInstanceHidden` النمط نفسه. تعيد مستندًا جديدًا ولا تغيّر المدخل أبدًا.

## تغيير التنسيق واللون

حقل `style` يحفظ خيارات، لا CSS:

```json
{
  "style": {
    "spacing": {
      "paddingBlockStart": { "base": "s6", "lg": "s8" },
      "paddingBlockEnd": { "base": "s6", "lg": "s8" }
    },
    "size": { "width": { "base": "wide" } }
  }
}
```

لا توجد إلا الخطوات والعروض التي يحددها القالب. ويحفظ حقل `colorScheme` معرّف
مجموعة ألوان مثل `"scheme-3"`؛ أما الألوان نفسها فتعيش في إعداد `colorSchemes`
الخاص بالمتجر، لا في مستند الصفحة.

## تغيير المصدر

عندما لا تكون القيمة قابلة للتحرير بعد، يكون التغيير في التعريف:

| التغيير | تغيير التعريف |
| --- | --- |
| خيار نصي جديد | أضف حقل `text` / `textarea` مع `key` |
| قيمة افتراضية مختلفة | غيّر `default` في الحقل |
| نص موروث مختلف | وجّه `contentKey` إلى مفتاح حزمة، أو غيّر الحزمة |
| خيار جديد | أضف حقل `select` مع `options` و`optionLabels` |
| مجموعة جديدة قابلة للتكرار | أضف حقل `list` مع `fields` للعناصر |
| السماح لقسم باحتواء كتلة جديدة | أضف النوع إلى قائمة `allow` في الفتحة |
| تخطيط ابتدائي جديد | أضف إعدادًا مسبقًا أو غيّره |

ثم شغّل تحقق كتالوج القالب واختباراته مرة أخرى.

## ما يجب ألا تفعله

- **لا تُعِد تسمية `type` أو مفتاح القالب (`key`).** تشير المستندات المحفوظة إلى النوع،
  وتعديلات نصوص التاجر مفهرسة بالقالب.
- **لا تحفظ URL صورة.** يحفظ حقل `image` مفتاح كائن الوسائط؛ ويُشتق URL عند العرض.
- **لا تكتب CSS في مستند صفحة.** استخدم خطوات التنسيق ومجموعات الألوان.
- **لا تتجاوز العمليات** للنقل أو الحذف أو التكرار أو الإخفاء إذا كان لديك
  كتالوج القالب. فالعمليات تعرف الفتحات والكتل المطلوبة والحدود.
- **لا تحرّر `dist/` أو بيانًا مُولّدًا.** حرّر التعريفات والمستندات؛ ثم أعد
  التوليد.

## العمل مع مساعد

أعطِ المساعد:

1. `manifest` القالب (أو تعريف المكوّن)،
2. المستند الهدف والسطح،
3. النتيجة الدقيقة التي تريدها،
4. أمر التحقق أو الاختبار الذي يستخدمه القالب.

اطلب منه فحص `DocumentIssue.code` بعد كل عملية، وتشغيل
`validateThemeDefinition(theme)` بعد تغيير تعريف. وتسرد الصفحة التالية القواعد
التي لا يجوز للمساعد تخمينها:
[استخدام الذكاء الاصطناعي لبناء قالب](/ar/sdk/theme/agents).
